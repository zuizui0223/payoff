## 2. What changed with Pseudomonas stutzeri

Before the P. stutzeri receipt, PAYOFF had mathematical reciprocal-invasion identification and several ecological analogues, but no published real system had been passed through the exact oriented-sign phase logic in the repository.

Dolinsek, Ramoneda & Johnson (2022), DOI `10.1038/s43705-022-00160-1`, changes that for the **generic game layer**.

The authors varied initial generalist:specialist composition and deliberately used the first three serial transfers for their reciprocal tests to minimize genetic/phenotypic change.

At pH 6.5:

```text
rare generalist increases  -> positive oriented generalist-in-specialist margin
rare specialist increases  -> positive oriented specialist-in-generalist margin
```

Therefore the two oriented signs are positive and the strict generic two-strategy sign phase is reciprocal invasion / protected coexistence.

At pH 7.5:

```text
rare generalist increase: certified
rare specialist increase: not certified (reported p=0.31)
```

The second result is coded `unresolved`, not negative. Set-valued partial identification leaves generic coexistence or generalist dominance as strict possibilities, plus a boundary, while excluding coordination and specialist dominance.

## 3. Why this is not architecture eta

For the published P. stutzeri receipt the labels

```text
S = complete denitrification generalist
D = nitrite-only specialist
```

are algebraic orientation labels only.

The specialist is not a validated differentiated/released architecture replacing an integrated architecture on the SCH/BALANCE/BITA bridge. Therefore:

```text
GENERIC_RECIPROCAL_INVASION_LOGIC_EMPIRICALLY_RECOVERED
```

is allowed, but

```text
PAYOFF_ARCHITECTURE_FREQUENCY_FEEDBACK_IDENTIFIED
```

is not.

No numerical architecture `phi` or `eta` is inferred from this study.

## 4. Time horizon is now an empirical gate

The same P. stutzeri system also supplies an important boundary.

The short three-transfer window is about 20 generations and was chosen to reduce type evolution. Over 12 transfers (~80 generations), treatments that initially showed specialist increase later changed because the generalist acquired altered nitrite-consumption phenotypes.

Thus the empirical object must include a declared time horizon:

```text
short pre-evolution window
    -> frozen-type reciprocal-invasion estimand can be identified

long evolutionary window with type change
    -> the same fixed payoff coordinates cannot be extrapolated unchanged
```

This is an evolving-game boundary, not a contradiction of the short-window sign receipt.

## 5. Architecture-specific empirical frontier

The strict Lane P/E1 admission rule remains:

```text
1. heritable integrated/shared architecture S
2. heritable differentiated/released architecture D
3. same net biological task
4. common relative-fitness scale
5. multiple S:D resident frequencies or reciprocal rare-resident support
6. the same strategic/heritable unit on the architecture and frequency axes
7. empirical rather than simulation-only decisive comparison
```

The closest current systems fail narrowly:

```text
Streptomyces coelicolor
    architecture mapping: exceptionally strong
    empirical frequency assays: present
    blocker: frequency unit is specialist cell vs WT cell/internal caste,
             not DoL-capable colony architecture vs generalist-only architecture

experimentally evolved E. coli cross-feeding consortium
    S->D origin from a common ancestral clone: recovered
    direct consortium-vs-ancestor competition: recovered
    common fitness scale: recovered
    blocker: only one total S:D starting composition in the direct competition,
             plus D is a multigenotype consortium
```

Therefore the literature gap is now sharply localized rather than broad.
