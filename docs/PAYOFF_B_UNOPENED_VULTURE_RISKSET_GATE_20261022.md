# PAYOFF-B: independent taxon GPS vulture full stationary-day risk set

Frozen 2026-10-22 after published source checksum/schema and spring-geometry
admission, but **before any local meteorological cue response is analyzed**.

The unopened Neophron percnopterus GPS package 10.5441/001/1.385gk270
has 577,329 geovalid original source fixes, 16 animal identifiers, and
18 animal-years with 30 3-day stationary→two-day northward candidate
windows. These are source geometry opportunities, not confirmed decisions.

Next source-only gate uses exactly the same original February–May
stationary 3-day risk entry, day4/day5 northward vs two-day stationary
vs other vs censored labels as PAYOFF-B's previous three-species
5,509-day analysis. It must exactly reproduce the 30 original
7-day-deduplicated source cases without changing any GPS thresholds.

Before making any NASA POWER external requests, construct only
0.5-degree source-grid × calendar-year × month counts of original
at-risk records. To proceed to an **exploratory** meteorological
source comparison: require >=10 raw northward labelled source days
with same grid/year/month stay opportunity, >=5 distinct overlap
grid-year-month strata, and <=500 unique monthly weather API batches
for the original source. Failure is reported without relaxing the
gate.

Original vulture conservation/habitat selection effects are prior art.
Although this is a different species and Movebank Study ID from
the three previously analyzed species, biological-level independence
and environmental cue availability are still unverified. No location,
year-specific nest site, animal ID or exact source date is exported for
this threatened bird.

No physical weather effects, migration hazard, population fitness,
forecast signal perception, game theory or information deadline are
estimated in this stage.
