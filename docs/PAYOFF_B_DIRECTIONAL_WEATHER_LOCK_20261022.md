# PAYOFF-B directional predecision wind / shortwave source pilot

Registered 2026-10-22, before reading the *V10M* and *shortwave* outcomes.
This follow-up is **exploratory after opening the T2M/WS10M pilot**, not a
confirmatory mechanism test or original V7/V8 registered hypothesis.

Use the exactly identical 144 SHA256-selected full stationary riskset
source day samples: 16 later-northward labels + 32 continued-stay labels
per each of Ciconia ciconia, Anser albifrons, Numenius arquata.
Original source GPS checksums, 3-day stationary eligibility, full panel
source counts and selected sample caps remain unchanged.

NASA POWER public hourly variables:
- V10M (m/s): physically northward component of **10m surface wind**.
  Positive values are northward flow, negative southward. For northbound
  birds this is a candidate broad wind-assistance proxy but NOT exact
  tailwind along intended flight route nor representative of flight altitude.
- ALLSKY_SFC_SW_DWN (W/m2): solar shortwave downward irradiance at surface.
  Can proxy solar input but is NOT measured turbulence, convection, thermal
  lift, physiological cost or realized migratory flight energy.

For each, require >=18 valid hourly observations on all eight UTC days:
the 24 hours before the third stationary source day versus the previous
seven days. Never use onward movement day meteorology as prior cue.

Report per-source, per-sampled-label original group means and differences
for previous-day and 7-day anomalies, plus month-level contrasts.
No individual GPS ID, location, date, or sampled weather pair is exported.
No species-pooled p value, claim of successful behavioral information
uptake, signed recourse, causal timing correction, or fitness.
