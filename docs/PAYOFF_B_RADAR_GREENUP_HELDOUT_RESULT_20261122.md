# PAYOFF-B 独立レーダー資料：緑化日は気温を超えて春の渡り通過時期を予測するか

**2026-11-22。原著の公表済みデータの探索的な年単位外部検証。結果：NO_ROBUST_PREDICTIVE_GAIN（肯定基準不成立）。**

## 主結果

eBirdを含まない独立した鳥類群集・気象レーダーのAdams et al. (2025)資料から、米国中部の**53レーダー地点、2003–2018年の16年、833地点年（完全ケース828）**を復元した。

**事前固定した比較**：従属変数はレーダー観測の春の通過中央値（`spring_q50`、通過数の累積50%に達する年内日付）。気温だけのベースラインモデルは「地点固定効果＋線形年トレンド＋観測された春の平均気温（`spring_mean_temp`）」。追加モデルは、同じ説明変数に衛星緑化日の地点年平均（`mean_greenup`）だけを足す。

解析に使っていない年を**年ごとに丸ごと1年**取り除き、その年の53レーダー地点について春の通過日を予測。16年の各MSEを等重みで平均した。

| 指標 | 数値 |
|---|---:|
| ベースライン平均年別MSE | **7.164544 日²** |
| 緑化日を追加した平均年別MSE | **7.184004 日²** |
| ベースライン−追加モデルのMSE改善量 | **−0.019460 日²** |
| 年ごとの誤差改善量のブートストラップ95%区間 | **［−0.095294, ＋0.049598］日²** |
| 緑化日追加でMSEが減った年数 | **9/16年** |
| 事前登録の肯定判定 | **不成立** |
| 全標本の記述的な緑化日係数（主検定ではない） | −0.009465 通過日／緑化日 |

事前固定の肯定基準は **95%区間の下限が正、かつ少なくとも10/16年でMSE改善**。両方を満たさなかった。正の結果を得るための年の取捨選択・別の春の通過分位数（q10/q90）・他の植物相指数・閾値変更は行っていない。

**生態学的解釈**：この既報の群集レーダー観測系では、地点ごとの差と年の傾向と春の気温に加えて植物の緑化日を与えても、未使用の年への通過時期の予測は明確に改善しない。著者らが既に公表した「通過期の温度関連が緑化との関連より重要」という結論に整合する**新しい同一原典の頑健性確認**であり、独立した新規生物学的発見ではない。

## 今回は「共線性で試験できなかった」わけではない

シカの親検証 PR #414 では、暦日と緑化からの遅れが強く重なったためVIF=16.54となり、あらかじめ固定したVIF上限10により係数を推定しなかった。

**今回は予測を実行できる構造だった**。モデルを実行する前に、元データのハッシュ・全列・地点×年の構造・欠測・共線性を点検し、次の通り原データの支持条件を凍結した。

|---|---|

| 原本SHA256 | `1751ca4cd523d632368ba7fbb27987c2d6c1cc4c1a9c75b8c67255476d799900` |

よって、強い共線性が原因で緑化日を検証できなかったのではない。**検証は成立し、その上で追加予測力が支持されなかった**。

## 解釈の境界

- 本資料は**53レーダー地点の春の移動群集**の観測であり、個体の出発・移動中の戦略・意思決定を直接追跡したものではない。シカと同じ個体単位の知見として合算しない。
- `spring_mean_temp` と `mean_greenup` はその季節が過ぎてから確定する測定量であり、**出発時に鳥が実際に知っていた未来情報や発行時点付き予測ではない**。この分析を「渡り鳥は緑化日の情報を利用しない」「最適情報価値がない」という因果的結論には使えない。
- `mean_greenup` は衛星植物フェノロジーの日付であり、鳥の餌の実際の生物量、昆虫出現量、繁殖成功を直接測っていない。
- 16個の留一年外テストは**同一データの依存する分割**で、16個の独立研究ではない。年ブートストラップ区間は条件付きの不確実性評価で、将来の気候体制への外挿を保証しない。
- 全標本の記述的な係数は、メカニズム上のゼロ効果を厳密に証明するものではない。気温と緑化の関係は既報であり、二次解析の予測結果も新しい追跡・因果実験ではない。
- **eBirdは使用していない。** 過去のPAYOFF E6の既知eBird派生研究も、この原本には結合していない。

## 次段の実証判断

PAYOFF-Bの現時点で検証が成功したのは、シカの個体内で遅い出発位相と短い滞在の関連が残ること。一方、暦と植物季節の直接識別（シカ）は不成立、独立のレーダー群集で気温を超える植物緑化の年外予測増分は**不支持**となった。

従って、論文で「鳥はより正確な植物フェノロジー情報を使って出発時期を調整している」と一般化する根拠はない。今後は気候・植物生長と**異なる時点で独立して変化する利用可能な情報、本人の行動、獲得できる資源や繁殖適応度**が同じ系・同じ意思決定単位で測られる原著データだけを候補にする。
