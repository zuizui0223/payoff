# PAYOFF architecture mapping protocol v1

Lane: **A only**.

The purpose of this lane is to decide whether an empirical pair instantiates the PAYOFF architecture contrast independently of any frequency-game result.

## Mapping target

```text
S = integrated/shared architecture
    one strategic unit carries coupled functions on a shared or constrained architecture

D = differentiated/released architecture
    the same net task is carried by a stable strategic unit whose functional roles are released, partitioned or modularized in the sense required by the registered PAYOFF/BITA bridge
```

The mapping is biological and mechanistic.  It is not inferred from coexistence, dominance, rare-type advantage or any fitted game parameter.

## Required A1--A6 evidence

```text
A1 integrated/shared candidate explicitly defined
A2 differentiated/released candidate explicitly defined
A3 matched net biological task / outcome
A4 heritable or otherwise stable strategic unit
A5 unit consistency across S and D
A6 mapping support independent of the observed frequency-game outcome
```

All six are required for a certified architecture mapping.

## Evidence allowed in Lane A

```text
genotype / genomic architecture
trait dimensionality
component or module assignment
functional perturbation
mechanistic allocation of functions
inheritance / stability of the strategic unit
matched-task assays
historical or experimental derivation of D from S
```

## Evidence not sufficient by itself

```text
negative frequency dependence
mutual invasion
stable coexistence
generalist-specialist terminology
specialist mixture > WT productivity
one strain is rare and has high fitness
an affine Delta(p) fit
eta != 0
```

These are Lane G outputs and cannot establish A1--A6.

## Unit-of-selection guard

The central failure mode in current near-E1 microbial systems is unit mismatch.

Example:

```text
Lane G frequency unit: specialist CELL vs WT CELL
Lane A architecture unit: DoL-capable COLONY vs generalist-only COLONY
```

This is not one S:D game.  The pair cannot be aligned merely because both measurements come from the same species or paper series.

Likewise, a two- or three-genotype consortium is not automatically one D architecture.  The lane must state why that consortium is a stable strategic unit on the same level as S.

## Current priority targets

```text
colony-level group benefit
```

Open A questions:

```text
Is there an empirical matched generalist-only colony architecture?
Is the DoL-capable colony itself the heritable strategic unit used in competition?
Can S and D be compared without switching from colony to cell as the unit?
```

### evolved E. coli cross-feeding consortium

Strength:

```text
actual emergence of differentiated ecotypes from one ancestor
reconstituted consortium beats ancestor on a common competition scale
```

Open A questions:

```text
Can the multigenotype consortium be treated as one stable D strategic unit?
Is its internal composition sufficiently stable / inherited for the intended PAYOFF comparison?
Does that unit match the unit whose total frequency would be varied in Lane G?
```

## Architecture-specific promotion

A successful Lane A receipt still does not license architecture frequency feedback.

Promotion requires, separately:

```text
Lane G PASS
Lane A PASS
same system
same comparison
same strategic unit
explicit pair-alignment receipt
```

Only then can an E1 architecture-specific frequency claim be considered.
