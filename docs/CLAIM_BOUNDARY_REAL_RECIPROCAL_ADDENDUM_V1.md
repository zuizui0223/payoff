## Newly allowed empirical statement

The repository now contains one published-data receipt showing that the **generic reciprocal-invasion sign-identification logic** works on real biological competition data.

For *Pseudomonas stutzeri* at pH 6.5, both rare types increased over the declared short pre-evolution window, so the oriented sign pair is `(positive, positive)` and the generic strict phase is reciprocal invasion / protected coexistence.

At pH 7.5, only the rare-generalist increase is certified. The rare-specialist test is unresolved, not negative, so only a set-valued partial phase is licensed.

Allowed labels:

```text
LANE_A_GENERIC_RECIPROCAL_INVASION_LOGIC_EMPIRICALLY_RECOVERED
PSTUTZERI_PH65_GENERIC_RECIPROCAL_INVASION_COEXISTENCE_RECOVERED
PSTUTZERI_PH75_GENERIC_RECIPROCAL_PHASE_PARTIALLY_IDENTIFIED
```

## Newly required empirical guardrail

Every empirical reciprocal-invasion or affine-frequency claim must declare the time horizon over which type identity is treated as fixed.

The same *P. stutzeri* study shows why: the short three-transfer assay was designed to minimize genetic/phenotypic change, whereas longer propagation produced altered generalist phenotypes and a different trajectory.

Allowed labels:

```text
EMPIRICAL_PAYOFF_TIME_HORIZON_REQUIRED

PSTUTZERI_LONG_WINDOW_FIXED_GAME_ASSUMPTION_NOT_SUPPORTED
```
