# PAYOFF-B 原データ時系列監査：緑化日は渡りの通過中央値より前だったか

**2026-11-22｜原著公表済みデータに対する探索的・事後の時間順序監査｜前後関係は有限標本の上下限、因果推定ではない。**

## 1. 結論

Adams et al. (2025) が公開した53気象レーダー地点・16年間の春の鳥類群集の通過中央値（`spring_q50`）と、同じ地点年のMODIS平均緑化日（`mean_greenup`）の相対的な時刻を確認した。両変数と春の平均気温が利用可能な**828地点年**のうち、**827地点年**で比較可能だった。2012年の緑化日が`−27`となる1地点年は年内DOYの1〜366から外れるため、意味を決めず未分類として保持した。

| 時系列の条件 | 判定可能な件数／827 | 未分類1件を含む全828地点年での厳密な割合範囲 |
|---|---:|---:|
| **緑化が渡りの通過中央値より前** | **739** | **89.25〜89.37%** |
| 緑化日が通過中央値の少なくとも1日前 | 739 | 89.25〜89.37% |
| **緑化が通過中央値の少なくとも7日前** | **688** | **83.09〜83.21%** |
| 渡りの通過中央値が緑化より前 | 81 | 9.78〜9.90% |
| 両者が同日 | 7 | 0.85〜0.97% |

一つの未分類レコードが任意のカテゴリに属する可能性を許し、各カテゴリの下限を`k/828`、上限を`(k+1)/828`として算出した。これは**統計的95%信頼区間ではなく、1件の解釈不確実性に対する算術的・論理的上下限**である。

年別16集計を調べると、渡りの通過中央値が緑化より前であった地点年が年内の多数派になる年は、未分類1件のどちらの解釈でも**0/16年**だった。年ごとにサンプル数は異なる。年間の全件集計は[機械可読の実測集計](../data/payoff_b_radar_greenup_chronology_bounds_result_20261122.json)に掲載するが、元の地点IDや個別行は配布していない。

## 2. PAYOFF-Bへの意味：追加予測力が弱い理由を「緑化が遅すぎる」だけにはできない

親[PR #415](https://github.com/zuizui0223/payoff/pull/415)では、同じ観測系・同じ828地点年で、地点の固定的違い・線形年トレンド・春の平均気温を使うモデルに緑化日を追加しても、16年の留一年外予測は改善しなかった。

- 気温のみ（＋地点・年傾向）：平均MSE **7.164544 日²**
- 緑化日を追加：平均MSE **7.184004 日²**
- MSE改善量 **−0.019460 日²**（年ブートストラップ95%区間 **［−0.095294, ＋0.049598］**）、改善9/16年、事前固定判定 **NO_ROBUST_PREDICTIVE_GAIN**

本監査から、少なくとも**群集の通過中央値**という粗い時点に限れば、緑化が先行していた地点年は大多数であり、約83%では平均緑化日が通過中央値より7日以上前だった。したがって、緑化日の追加予測力が乏しかったことを、単に「緑化現象がまだ起きていなかった」とする説明だけで片づけることはできない。

これは**新しい行動機構の肯定結果ではない**。全季節が終わった後に算出した緑化日と春の通過中央値を並べた後ろ向き比較である。緑化を鳥が観測した時刻、鳥の感覚・予測、実際の情報伝達、修正可能な移動・滞在選択、餌の現存量や繁殖成功を測ったわけではない。衛星緑化の現象が始まれば鳥は何らかの環境情報を徐々に感知できる可能性がある一方、衛星指標の平均緑化日は鳥の利用した明示的な情報とは限らない。

**一つの群集通過中央値が緑化より後でも、その時点までにすでに約半分の渡りが通過していることに注意。** この集計は全個体の出発前情報の可用性、行動の最適性、学習、相手との協調を識別しない。

## 3. なぜ一つの年外DOYに対して上下限を使ったか

初期の[厳格な時系列契約](../data/payoff_b_radar_greenup_chronology_contract_20261122.json)では両時刻をDOY 1〜366に限定した。原本ハッシュが一致したデータの診断では、`spring_q50`の最小／最大は**106／137**、`mean_greenup`は**−27／178**。緑化日が1未満なのは**2012年の1行**で、それ以外は範囲内だった。原データでこのマイナス値が前年の緑化を表すのか、計算規約・特殊値によるものかは確定していない。

このため厳格な主解析を元のルールどおり**HOLD_REQUIRES_SOURCE_SEMANTICS**と判定し、[範囲診断結果](../data/payoff_b_radar_source_doy_range_diagnosis_20261122.json)を保存した。丸め誤差のテストは修正したが、原資料の`−27`は勝手に修正しなかった。

その後、**出典の意味が未確定な1行をどちらとも決めない**別契約を保存した：[事後の上下限感度分析契約](../data/payoff_b_radar_greenup_chronology_bounds_contract_20261122.json)。この計算は厳格主解析の成功へのすり替えではなく、既知の1件の不確実性が全体の割合に与え得る最大差を明示するもの。各割合の上限と下限の幅は**1/828、約0.121パーセントポイント**となる。

2012年に未分類の元レコードが1件あるため、未分類行を単に分母から除いた`739/827`などの割合を「全828地点年の結果」としては報告していない。

## 5. 研究判断

**観測事実としては緑化は多くの地点年で通過中央値より先だったが、その緑化情報が鳥の行動選択に使われた証拠はない。** 緑化の利用可能性（粗い現象の先行）と、緑化の追加予測力と、鳥の実際の情報利用は3つの異なる推定対象である。

PAYOFF-Bの新しい「情報の利用時点×残された修正可能性×相互作用相手との協調」を主張するには、同じ個体・同じ意思決定で、事前時点の情報、行動後の修正の選択肢、資源や適応度の成果を独立に測る必要がある。これが得られない限り、今回の相関や時系列上の先行を因果的な情報利用結果として原稿へ昇格させない。
