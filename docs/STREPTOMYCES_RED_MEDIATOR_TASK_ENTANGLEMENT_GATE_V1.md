# Streptomyces RED mediator-task entanglement gate v1

Lane: **A task-match subgate only**.

Status: **prospective**. No direct `mu` outcome has yet been opened, and the required matched generalist/shared Streptomyces architecture remains unrecovered.

## Why this gate is needed

The RED/prodiginine perturbations were selected as mechanism probes because they can test whether RED/prodiginine contributes to terminal genomic specialist generation. But RED/prodiginine is also part of the biological output altered by those same perturbations.

Therefore a RED-deficient strain can answer

```text
Does RED/prodiginine contribute to the registered differentiation-generation pathway?
```

without automatically answering

```text
What would a matched generalist/shared architecture do while preserving the same net biological task?
```

Those are different counterfactuals.

## Three admissible routes to task matching

A future S candidate may pass this subgate only through one of the following routes, declared independently of Lane G.

### Route 1 — direct task preservation

The differentiation-suppressing intervention leaves the predeclared task measurably intact in the same ecological context.

### Route 2 — separation of function

A perturbation selectively reduces the differentiation-generating activity while retaining the relevant task output. This is the cleanest route when one molecule or pathway has both task and mediator roles.

### Route 3 — orthogonal task rescue

The relevant net task is restored through a route independently shown not to re-establish the differentiation-generation pathway being suppressed.

## Why simple same-mediator add-back is not enough

If RED/prodiginine itself contributes to both the task and the generation pathway, adding the same mediator back can restore both. Such an add-back can demonstrate biochemical rescue, but by itself it does not construct a shared/generalist architecture in which the task is preserved while the differentiation mechanism remains off.

Thus:

```text
same mediator add-back != orthogonal task rescue
```

unless additional evidence separately shows that the rescue does not restore the generation pathway.

## Relation to the promotion firewall

The mechanism-to-architecture promotion gate requires both:

```text

```

This subgate supplies only the task-matching component of the second block. Passing it would still not establish matched background, strategic-unit equivalence, generalist-only state, or Lane G frequency response.
