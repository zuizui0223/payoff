## Fixed analysis

Endpoint: Total_seeds per plant; zero retained, missing excluded, no log transform of individual count, no pseudocount. Each plot has one snow/frost assignment. Require one row per plot/plant (duplicate or conflicting allocation => HOLD; no silent aggregation). Require each included plot have both pollen arms observed. Missing pollen or seed values excluded explicitly. Within each included plot, average observed seed counts separately by treatment; plot—not plant—is the snow/frost randomization unit. For each species, four snow/frost strata must each contain >=5 paired plots. Both frost levels retained regardless of direction; compute each snow-by-pollen arm mean by equal weighting the two frost stratum-specific mean plot rates. Estimate low- and high-pollen log snow-removal response, and their difference:
```
theta_snow = log(W_Removal,AP/W_Natural,AP) - log(W_Removal,NP/W_Natural,NP)
```
Also report four means, four arm plot support, exclusions and natural/added additive contrast difference as descriptive sensitivity. For log ratios require strictly positive arm means. Within each species resample whole plots separately in each of the four snow/frost strata 10,000 times, seed 20261125, preserving both pollen arms, recompute all means/contrasts. Report percentile CI and bootstrap sampling variance of theta_snow if all draws finite; otherwise HOLD for log-scale CI, no pseudocount. A positive theta is attenuation only if no-added snow contrast is negative; report both irrespective of sign. No pooling across three species, because plots and cohort overlap; no cross-species covariance estimated. Report complete-case support and imbalance, not an ITT analysis if attrition is present.

## Claim boundary

Snow removal randomized phenological shift and abiotic exposure, not pure partner mismatch; pollen addition independently manipulates supplied service, not endogenous corrective ability. Study already reports no pollen supplementation effect across tested species. This new contrast isolates a **snow-removal × pollen-supply interaction on mean seeds per plant**, not a direct effect of mismatch or physiological recourse. Lower/higher initial snow effect is not assumed. No positive selection of species after seeing outcomes. This is a compatible mathematical log-mean interaction but a distinct secondary ecological estimand; frozen primary theta admission stays 0. No manuscript merge or replacement.
