# PAYOFF-B greater snow goose empirical lane map

Date: **2026-09-30**  
Status: **pre-outcome routing map**

The greater-snow-goose programme is the strongest current same-lineage bridge
for PAYOFF-B information deadlines, but its components must be opened in a
fixed order and must not be conflated.

## Gate 0 — source access and route geometry

Required before any focal GPS outcome is opened:

- authorized Movebank event access;
- frozen movepp preprocessing;
- source-backed shared route-context geometry;
- historical NARR predictive-connectivity construction using only years before
  each focal migration year.

Current claim status: **operationally prepared; external access/geometry remain
gates**.

## Lane 2 — downstream dual-use compensation screen

Registered unit:

\[
\text{individual}\times\text{completed forward route transition}.
\]

Primary response:

\[
\log(\text{transit duration to next observed downstream context}).
\]

The screen retains route skipping rather than discarding it. A secondary
actuator asks whether warm predictive cues increase the probability of skipping
the next intermediate route context.

Primary interpretation is deliberately asymmetric:

- supported cue-linked transit compression -> focal-cue exogeneity is not
  licensed; theorem-level interpretation must use a dual-use model;
- null/imprecise -> dual-use not demonstrated, but exogeneity remains
  unresolved.

Support additionally requires a negative sign in every
leave-one-context-year-out refit across at least 12 context-year cells.

## Lane 3 — effective waiting-cost calibration

The theorem requires the total fitness-equivalent cost of natural information
waiting:

\[
D_{\mathrm{eff}}
=
J(\delta)
+
\min_c[K(c)+M(\delta-c)].
\]

Two valid identification routes are frozen.

### Total-effect route

A biologically faithful waiting intervention that allows ordinary downstream
compensation identifies

\[
D_{\mathrm{eff}}^{causal}(\delta)
=
E[Y(0)]-E[Y(\delta,\mathrm{adapt})].
\]

### Mechanistic route

Independently estimate:

- direct nonrecoverable waiting cost \(J\);
- raw delay \(\delta\);
- compensatory capacity;
- compensation cost \(K\);
- residual timing loss \(M\).

Current snow-goose captivity experiments are **D-like perturbation evidence**
but not natural \(D_{\mathrm{eff}}\), because captivity adds handling,
confinement and stress.

Historical migration and pre-laying correlations are **buffering anchors**, not
causal compensation parameters.

Current claim status: **not identified**.

## Lane 4 — behavioral threshold

Only if the departure lane is estimable may the frozen descriptive
\(q\)-threshold grid be opened.

Any identified threshold remains a behavioral/phenomenological threshold until
it is compared with an independently estimated \(D_{\mathrm{eff}}\) and common
state-loss scale.

If the compensation screen supports dual use, the fixed-cost inverse identity
must not be interpreted as a cue-independent actor trait. The threshold instead
solves

\[
V_A(q)=D_{\mathrm{eff}}(q).
\]

## Lane 5 — single-actor theorem test

A strong single-actor information-deadline test requires the same ecological
decision system to supply:

1. pre-commitment cue reliability \(q\);
2. independently identified \(D_{\mathrm{eff}}\), or \(D_{\mathrm{eff}}(q)\)
   under dual use;
3. state-mismatch losses on the same utility scale;
4. observed cue-use switching across sufficient \(q\) support.

This would test whether an observed threshold agrees quantitatively with the
independently predicted threshold.

It would be materially stronger than the current separate-link evidence.

## Lane 6 — what snow goose still would not prove

Even complete success in Lanes 1–5 would not by itself demonstrate the
**pairwise asynchronous information-use window**

\[
q_1<q\le q_2
\]

for interacting ecological partners.

Greater snow goose is currently a single-species decision system. It can test
the actor-level deadline mechanism and the fixed-versus-dual-use distinction,
but not the full pairwise interaction theorem unless a second interacting actor
with an independently measured threshold is introduced.

The pairwise theorem therefore remains a separate prospective target.
