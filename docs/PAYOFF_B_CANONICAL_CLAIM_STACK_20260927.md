# PAYOFF-B canonical information-coordination claim stack

Date: **2026-09-27**  
Status: **canonical scientific state for the information-coordination generation**

## One-sentence conclusion

> **Seasonal coordination can fail not because information is absent, but
> because interacting organisms begin using the same information at different
> decision thresholds; once an information-using convention collapses,
> restoring even perfect environmental information need not restore ecological
> coordination.**

## Exact theory

### T1 — information has an action threshold

Define

A = (1-pi) C_F

and

L = pi C_M.

A symmetric cue does not change behaviour until its reliability exceeds

q0 = max(A,L)/(A+L).

Below q0, more accurate information can have zero behavioural value.

### T2 — decision deadlines determine cue uptake

With waiting or opportunity cost D, an actor begins using the cue above

q_wait(D) = [max(A,L)+D]/(A+L),

provided D < min(A,L).

If D >= min(A,L), the actor never waits, even for perfect information.

Therefore **cue quality and cue use are distinct ecological state variables**.

### T3 — better information can transiently worsen coordination

For two actors with D1 < D2 < min(A,L), information uptake is asynchronous over

q_wait(D1) < q <= q_wait(D2).

Its exact width is

Delta q = (D2-D1)/(A+L).

Below that interval both actors ignore the cue; above it both use it. Mismatch
can therefore follow zero -> positive -> zero while cue reliability improves
monotonically.

Canonical witness:

pi = 0.4, C_F = 2, C_M = 1,

D1 = 0.10, D2 = 0.30,

giving q1 = 0.8125 and q2 = 0.9375. On the frozen 0.01 grid the window is
q = 0.82--0.93.

### T4 — asynchronous community uptake is a network cut

At cue quality q, let S(q) be the set of information users. For symmetric edge
weights, temporal mismatch generated by asynchronous cue uptake occurs on the
weighted cut between S(q) and its complement.

If C(q) is that cut weight, W total interaction weight, and M(q) the
probability that the informed action differs from the old convention,

E(q) = M(q) C(q)/W.

For a complete network with N actors and k information users,

C/W = 2 k (N-k) / [N(N-1)].

The informed--uninformed edge boundary is therefore largest near half uptake.
In the large-population random-mixing limit,

P(user--nonuser pair) = 2 f (1-f),

which peaks at f = 1/2.

This is a statement about the asynchronous interaction boundary, not a claim
that total natural mismatch must peak at exactly 50% uptake.

### T5 — network placement of deadlines matters

If uninformed node i becomes informed, the exact change in cut weight is

Delta C_i
= weight(i, still-uninformed neighbours)
- weight(i, already-informed neighbours).

The same distribution of waiting costs can therefore generate different
mismatch trajectories depending on whether early information users occupy
peripheral, central, bridge, or clustered positions.

### T6 — information acquisition has a coordination wedge

When timing errors impose partner costs, the joint value of waiting can exceed
the focal actor's private value.

If V_J(q) > V_P(q), every delay cost in

D in [V_P(q), V_J(q))

creates a region where the individual rationally commits now while joint payoff
would be higher if it waited.

Coordination failure can therefore begin before seasonal action selection.

### T7 — perfect information need not restore information use

At q = 1, let R_i be prior mismatch risk under the old convention, D_i the
information cost, I_i interaction strength, and p the probability of the state
in which the informed action differs from the old action.

The old profile is stable when

D_i + p I_i >= R_i.

The informed profile is stable when

D_i <= R_i + p I_i.

Both are strict equilibria when

|D_i - R_i| < p I_i.

The informed state has higher joint payoff when

sum_i D_i < sum_i R_i.

Thus perfect environmental information, a higher-payoff informed solution, and
physical response capacity can coexist with a strictly stable obsolete timing
convention.

### T8 — temporary information degradation can produce recovery failure

In the frozen three-player shared-cue witness, the exact lower stability
thresholds of the informed profile are approximately 0.583, 0.667 and 0.800.
The migrant sets the system boundary at q = 0.80.

Path-preserving best response retains the informed state at the exact tie and
collapses to late|late|late at q = 0.79 on the 0.01 grid.

When cue reliability is restored to q = 1, the network remains in the obsolete
state.

At perfect information:

- obsolete joint payoff = -0.60;
- informed joint payoff = -0.45;
- unilateral first-adoption gains = (-0.15, -0.20, -0.10).

Therefore:

**environmental information recovery does not imply ecological coordination
recovery.**

### T9 — acquisition memory and topological memory are distinct

The symmetric shared-cue acquisition trap occurs across complete, chain and
migrant-star canonical networks.

The earlier heterogeneous private-cue game gives a different result. Under the
strict phase diagram:

- complete: 118/391 eligible cells show strict lower-payoff hysteresis;
- chain: 52/364;
- migrant-star: 0/404.

PAYOFF-B therefore distinguishes:

1. **acquisition memory** — an information-using convention does not restart;
2. **topological memory** — a heterogeneous displaced timing configuration is
   stored or erased depending on network structure.


### T10 — recovery can be nucleated by a temporary informed seed

At perfect information, let S be a temporarily informed seed and let a_i(S) be
the fraction of an uninformed actor i's interaction weight already attached to
informed neighbours. Its exact adoption gain is

H_i(S) = R_i - D_i + p I_i [2 a_i(S) - 1].

With non-negative interaction weights this gain is non-decreasing as adoption
spreads, so recovery is a progressive threshold cascade.

In the canonical three-species chain, the central local pollinator is the
unique singleton rescue seed; either peripheral species alone fails to restart
the full informed state. In the complete and migrant-star canonical networks,
any singleton can nucleate recovery.

Licensed wording: **a coordination trap can be theoretically recoverable by a
small, strategically placed temporary information seed.**

Not licensed: a natural singleton rescue species has been identified, or a
one-species manipulation is a management prescription.


## Natural evidence

### E1 — broad birds

The preregistered pooled predictive-connectivity coefficient is -0.0462,
95% CI [-0.0870, -0.0054], p = 0.0265 across 3,311 rows from 37 species.

All leave-one-species-out and leave-one-year-out coefficients are negative.
However, species-, route- and cell-year-clustered intervals cross zero.

Licensed wording: **pooled directional support with dependence-sensitive
uncertainty**.

### E2 — flycatcher timing experiment

Manipulated resident-tit phenology was largely unavailable to earlier male
settlement and showed no detectable male settlement effect, whereas later
female settlement and pairing responded to the treatment.

Licensed wording: the same heterospecific seasonal state can be unavailable to
an earlier decision and behaviourally relevant to a later one.

Not licensed: females deliberately waited to obtain information.

### E3 — wigeon

The registered origin-phase by predictive-connectivity interaction is +0.0202,
95% CI [-0.1058, 0.1461], p = 0.756.

Status: **NOT_SUPPORTED**.

Thus information before commitment is not the same as correction after error
appears.

### E4 — long-term natural recovery gate

The 1980--2010 Hoge Veluwe lane is **NO_CUE_DRIVER_REVERSAL**.

The cue--driver relationship is nonstationary, but the preregistered
decline-to-recovery gate fails and the path-dependence model was not opened.

No current natural dataset is promoted as direct information-triggered network
hysteresis.

### E5 — prospective same-system cue-resource recovery gate

A second preregistered Hoge Veluwe lane used the same fixed Ivory Coast cue but
targeted observed caterpillar peak dates directly, before opening any
resident-migrant timing history.

Across the frozen 1992–2015 connectivity series, the best segmented fit
improved AICc by 10.81 units but had positive slopes both before and after its
1999 breakpoint (+0.228 and +0.027).

Status: **NO_CUE_RESOURCE_REVERSAL**.

Because the environmental decline-to-recovery prerequisite failed, Gate C was
**NOT_RUN** and pied-flycatcher/great-tit timing was not joined into a history
test.

Licensed wording: the strongest current same-system prospective validation
failed before the network-history outcome was opened.

### E6 — cross-system information-distance triangulation

A frozen reanalysis of the Usui et al. migratory-bird meta-analysis retains
944 temperature-response effect rows from 28 studies and 279 species.
Inverse-variance meta-regression with two-way Study x Species clustered
uncertainty gives the adjusted long-minus-short migration-distance contrast

    +0.421 d / °C
    95% CI [+0.121, +0.722]
    p = 0.0077.

Because more negative slopes mean stronger advancement in warm years,
long-distance migrants are less temperature-responsive than short-distance
migrants. The contrast remains positive with a 99th-percentile weight cap
(+0.417, 95% CI [+0.118, +0.715]) and in an unweighted adjusted fit
(+0.538, 95% CI [+0.190, +0.887]).

All 28 leave-one-study-out refits retain a positive coefficient and a positive
95% CI lower bound (coefficient range +0.378 to +0.608 d / °C; smallest lower
bound +0.066; largest p = 0.0195).

This is a reconstruction of an effect already reported by Usui et al., not a
new PAYOFF-B discovery.

Photoperiodic and endogenous migration programmes are retained as a
non-exclusive alternative explanation for weaker short-term temperature
responsiveness in long-distance migrants. E6 therefore does **not** causally
identify information distance; endogenous control may itself contribute to, or
covary with, early commitment.

An independent local-system benchmark reconstructs 1,763 species-level
temperature slopes from Freimuth et al. The five published group counts and
rounded means reproduce exactly after three declared taxonomy-name overrides:

- plants: n = 1,438, mean -5.152 d / °C;
- bees: n = 20, mean -2.024 d / °C;
- flies: n = 22, mean -3.879 d / °C;
- butterflies/moths: n = 206, mean -1.848 d / °C;
- beetles: n = 77, mean -1.706 d / °C.

Licensed wording: **within migratory birds, phenological temperature
responsiveness weakens with migration distance; independently, local
plant--pollinator partners show strong but unequal temperature responsiveness.
Together with E1, these patterns are consistent with an information-distance
axis.**

Not licensed: a causal pollinator-versus-bird coefficient, a universal
taxonomic ranking, or a claim that these two sources alone constitute a new
cross-taxon meta-analysis.

The current natural evidence also does not estimate **D2-D1** within a specific
interacting pair and does not observe the predicted **q1 < q <= q2**
desynchronization window. The pairwise deadline-difference mechanism remains a
prospective natural test.

## Prior-art firewall

PAYOFF-B does not claim novelty for game theory applied to phenology,
informational mismatch, remote migration cues, environmental predictability,
cue--driver decoupling, costly information acquisition, noisy-information
Bayesian games, generic coordination traps, or generic ecological hysteresis.

The closest direct predecessor is Tomotani et al. (2021), which already
proposed climate-driven disruption of the relationship between migration cues
and later drivers of selection.

## Current novelty candidate

The contribution begins after cue reliability is allowed to change:

cue reliability
x heterogeneous decision deadlines
-> asynchronous information uptake
-> network cut / transient mismatch
-> coordination barrier to first adoption
-> possible historical lock-in after cue recovery
-> derived rescue threshold and topology-dependent seed leverage.

The compact conceptual claim is:

> **Information use, not information alone, is an ecological state variable.**

The strongest counterintuitive result is:

> **Better information can worsen coordination during asynchronous uptake, and
> after an information-using convention collapses, even perfect information may
> fail to restore it.**

## Role of temporal buffering

The older conclusion that temporal buffering delays but does not permanently
replace spatial tracking remains valid as the **capacity layer**.

It is no longer the primary novelty claim.

The integrated framework is:

1. capacity — can the organism execute enough response?
2. prediction — does current information predict the later state?
3. deadline — is waiting for better information worth its cost?
4. uptake frontier — who in the interaction network currently uses it?
5. strategic accessibility — is first adoption individually profitable?
6. memory — does a timing convention persist after the environmental cause
   disappears?

## Current headline

> **Theory predicts that environmental information can recover before
> ecological coordination does.**

## Claim ceiling

Natural data support several edges of the mechanism but not the full
degradation-recovery network hysteresis.

The recovery-hysteresis conclusion therefore remains exact theory plus a
prospective ecological prediction, not an observed natural event.
