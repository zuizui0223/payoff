# PAYOFF-B: two nonoverlapping 12h GPS windows in original shearwater intervention

Pre-source-measurement gate frozen **2026-10-28** (the original 2015
experimental treatment and homing results are known PRIOR ART).

Original published Scopoli's shearwater CC0 (Movebank DOI
10.5441/001/1.tc76g560; Pollonara et al. 2015). Original 32 allocated
birds: 9 control, 9 magnetic disruption, 14 olfactory deprivation.
The paper explicitly assigned GPS to 9/9/9; the remaining 5 anosmic birds
were Argos equipped BY DESIGN. Original released GPS capture:
8 control, 9 magnetic, 6 olfactory. No Argos-bird outcome can be made
an equivalent high-frequency GPS record.

The GPS original logger was nominally fixed at 5-minute intervals, but
in-source recorded continuous coverage differs with return/loss, battery
or interference. Because the magnetic treatment device may trigger the
magnetically actuated GPS switch, **track absence/gaps are potential
treatment-dependent detection**, not random missing data.

Without reading a course-correction or ecological outcome, check each
original GPS animal relative to **its first observed valid fix**:
- one early observation segment [0,12h) and a later [12,24h] segment;
- >=6 distinct GPS timestamps in EACH segment;
- at least one timestamp in first 2h and last two hours of each window;
- no observed gap >3h within either segment, <=4h across the 12h boundary;
- source gate: >=5 original GPS animals with BOTH windows in EACH group.

This measures only whether individual-level early-vs-late correction
might be analysed with comparable timing. It does NOT establish the
first original GPS fix equals experimental release time, whether a
bird encountered land/olfactory cues, which way it steered, or whether
it returned successfully; none is opened as an outcome.

Original human/treatment arms, sensor allocations and original source
CC0 file byte/MD5 must be reverified. No individual ID, GPS fix,
site coordinate, real event date or per-bird score is published. All
failures and incomplete windows are recorded. Failing the threshold
does not justify relaxing the source gate after seeing data. Under
n small and arm-specific attrition, any future behavioral result
requires predeclared nonrandom-missing-outcome bounds and does not
supplant original Pollonara findings.
