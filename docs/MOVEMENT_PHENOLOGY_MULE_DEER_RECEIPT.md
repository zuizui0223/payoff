# PAYOFF-B Stage-3 mule-deer phase-feedback receipt

Status: **independent empirical validation result; observational, not causal**.

Source: official Nature Communications source-data workbook for Ortega et al. (2023), DOI 10.1038/s41467-023-37750-z.

## Sample

~~~text
N_ANIMAL_YEARS = 152
N_INDIVIDUALS = 72
N_YEARS = 8
YEARS = 2011, 2012, 2014, 2016, 2017, 2018, 2019, 2020
~~~

For each year, annual green-wave propagation speed was estimated from the published relationship between route distance and the day of peak instantaneous rate of green-up.

The empirical relative-speed analogue is

\[
u_{\rm macro}
=
\frac{\text{animal mean migration movement rate}}
{\text{annual green-wave propagation speed}}.
\]

Phase error is the published "days from peak IRG" at migration start:

~~~text
E_start > 0  animal starts after the local green-wave peak
E_start < 0  animal starts before the local green-wave peak
~~~

## Result 1 — phase error strongly controls relative movement speed

The registered controller model is

\[
\log u_{\rm macro}
=
\alpha+\kappa E_{\rm start}.
\]

Point estimate:

~~~text
kappa = 0.0182989 log-speed-ratio units per day
ordinary 95% CI = 0.01618 .. 0.02042
~~~

This corresponds to approximately

\[
e^\kappa-1 \approx 1.85\%
\]

higher relative movement speed for each additional day that migration begins behind the green-wave peak.

Individual-clustered inference:

~~~text
cluster SE = 0.001223
cluster p = 1.21e-50
~~~

With year fixed effects:

~~~text
kappa = 0.0189874
individual-clustered SE = 0.001302
cluster p = 3.47e-48
~~~

The feedback slope is positive in all eight fitted years.

Therefore the stabilizing sign of the response is not generated by one anomalous year.

## Result 2 — animals use both speed and stopover as control levers

The published migration summaries show that later-starting animals move faster and spend less time in stopover.

For stopover duration:

~~~text
beta = -0.492 stopover days per +1 day of start phase error
individual-clustered p = 6.07e-37
~~~

With year fixed effects:

~~~text
beta = -0.614
individual-clustered p = 5.89e-43
~~~

Thus animals that begin later relative to the green wave simultaneously increase travel rate and reduce stopover time.

## Result 3 — phase error is compressed during migration

Median absolute phase error:

~~~text
start = 19.86 days
end   =  7.72 days
~~~

Mean absolute phase error:

~~~text
start = 21.91 days
end   = 11.12 days
~~~

The individual-clustered mean reduction is

~~~text
10.79 days
SE = 1.41 days
p = 2.28e-14
~~~

Regression of end phase on start phase gives

~~~text
DFP_end ~ DFP_start:
slope = 0.107
cluster p = 0.032
~~~

With year fixed effects:

~~~text
slope = 0.093
cluster p = 0.082
~~~

The exact compression slope is therefore less robust than the speed/stopover feedback itself, but the direct absolute-error reduction is strong.

## Result 4 — fitted stable phase is nonzero

The fitted relative-speed controller has

~~~text
u0 at zero phase error = 0.8565
kappa = 0.0182989
~~~

so the speed crossover \(u=1\) occurs at

\[
E_*
=
-\frac{\log u_0}{\kappa}
=
8.46\ {\rm days}.
\]

Using individual-clustered coefficient covariance, the delta-method uncertainty is approximately

~~~text
E* = 8.46 days
SE = 2.30 days
approx. 95% interval = 3.95 .. 12.98 days
~~~

This is a key conceptual result: tracking does not imply zero lag. The fitted controller stabilizes a positive phase offset relative to the remotely sensed vegetation peak.

## Result 5 — correction has a spatial scale

The median annual green-wave propagation speed is

~~~text
c_e = 5.614 km/day.
~~~

Under the local phase-feedback model,

\[
\ell=\frac{c_e}{\kappa}
\]

is the e-folding distance for a small phase perturbation.

Point estimates:

~~~text
e-folding correction distance = 306.8 km
half-error distance           = 212.6 km
~~~

Using clustered coefficient uncertainty and treating the median environmental speed as fixed:

~~~text
SE(ell) ≈ 20.5 km
approx. 95% interval ≈ 266.6 .. 347.0 km
~~~

This creates a cross-system quantity directly comparable with route length and barrier spacing.

## Interpretation

The mule-deer result supports a **closed-loop phase-correction mechanism**:

~~~text
late relative to resource wave
        ↓
increase movement rate
reduce stopover
        ↓
phase error shrinks during migration
~~~

The result is stronger and more biologically interpretable than asking whether all animals move at one universal speed ratio.

It motivates the PAYOFF-B extension:

\[
\text{fixed-rate timescale matching}
\quad\rightarrow\quad
\text{state-dependent phase-error feedback}.
\]

## Claim ceiling

Licensed:

- a strong observational association between initial phase error and relative movement speed;
- the stabilizing sign is reproduced in all eight years;
- stopover duration changes in the compensatory direction;
- absolute phase error is substantially lower at migration end;
- a fitted nonzero stable phase and spatial correction scale can be defined under the registered controller model.

Not licensed:

- causal proof that phase error itself triggers the behavioral adjustment;
- a direct lifetime-fitness optimum;
- evidence that the fitted \(E_*\), \(\kappa\), or \(\ell\) are universal constants;
- proof that the exponential controller is the evolved decision rule;
- direct equivalence with the fixed-rate PAYOFF-B anti-phase theorem.

The next replication target is an independent avian system with explicit differences in environmental predictability or route barriers.
