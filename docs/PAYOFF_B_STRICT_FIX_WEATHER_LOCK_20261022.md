# PAYOFF-B unchanged weather sensitivity on strict GPS-fix stable source windows

Frozen 2026-10-22 AFTER historical full-source stork/goose/curlew/vulture
solar-temperature patterns were opened, but BEFORE querying strict-subset
NASA meteorology. This is explicitly post-outcome measurement sensitivity.

A completed GPS original-fix integrity audit found that daily-centroid
3-day stationary source labels often mask excursions beyond the same
original 30km anchor circle. This can cause outcome-differential source
entry errors. The current strict method retains an original riskday ONLY
when all recorded fixes on EACH of its three anchor days are <=30km
from the original unchanged source circle. No new source days, species,
years, GPS movement labels or weather variables are introduced. Short
foraging excursions may also be excluded, so this defines a strict
source-quality subset, not real resting bird behavior.
