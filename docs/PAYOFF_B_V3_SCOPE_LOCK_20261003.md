# PAYOFF-B V3 scope-lock rule

Date: **2026-10-03**  
Status: **superseded as the active change-control rule by `PAYOFF_B_V3_SCIENCE_FREEZE_20261003.md`; frozen GEB V2 unchanged**

## Main-text spine

The V3 main-text scientific spine is fixed as:

1. information can improve while actionability declines;
2. a developmental/physiological entry timer determines entry timing and initial phase state;
3. a post-entry information-dependent controller corrects signed phase error;
4. partner differences in entry state and/or phase retention generate interaction mismatch;
5. coordination and irreversibility can prevent recovery;
6. natural evidence is layered and explicitly bounded.

Clock-portfolio theory is retained outside the V3 main text as prospective supporting/future theory, not a co-equal Abstract spine.

## No additive theory creep

After this lock, a new theoretical result can enter the V3 main text only if it:

- replaces or simplifies an existing result rather than merely adding another layer; or
- is required to interpret a genuinely new independent natural test that passes its predeclared admission gate.

Otherwise it belongs in theory/, Supporting Information, or a future paper.

## Current extension placement

- persistent physiological-state model: Supporting / post-hoc extension;
- clock-portfolio optimization: supporting/future theory;
- opportunity-loss fragility: supporting/future prospective theory;
- cryptic portfolio divergence: supporting/future prospective theory;
- loss/substitution/selection identification triangle: empirical-method guard / SI;
- generic control-theory derivations: prior-art implementation details / SI.

## Natural-data rule

Existing post-freeze datasets cannot be re-mined to rescue a failed or unavailable direct test by changing endpoints or thresholds.

New natural evidence enters the main manuscript only when:

- the hypothesis or admission rule was declared before its focal outcome;
- the dataset solves a specific identification gap;
- inferential status is labeled as preregistered, source-data reanalysis, published anchor, post-hoc, or prospective.

## Word-count rule

Target main body remains <= 5,000 words.

A new main-text paragraph requires removal or compression of comparable material elsewhere.

## Override

This is a scope-management rule, not an immutable scientific ban. It can be explicitly reopened if a new independent dataset or conceptual correction materially changes the paper's central conclusion.
