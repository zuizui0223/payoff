# PAYOFF-B: continuous GPS reveals the 16-hour apparent timing limit was mostly a day-boundary construction

**2026-10-22 | Original public CC0 source measurement audit | No new ecological effect**

The earlier Egyptian-vulture Neophron percnopterus published GPS audit had retained 18 original first-per-animal-year northward source candidates (30 original deduplicated possible events). Measuring from each anchor-day LAST original GPS fix to the following-day FIRST outside-30km GPS fix produced 15 intervals ≤24h, with 16h median, and three records where the LAST anchor-day fix was already outside. This looked like limited temporal resolution for ecological decision analysis.

Before the new source continuous position-to-position results were opened, a protocol locked comparison within the **same 18 original animal-years and unchanged first-event source labels**. Original GPS checksum and source event counts were verified again. Rather than force a UTC midnight split, the new audit reads every original GPS fix around each original stationary-source day and reports the first consecutive original inside ≤30 km to outside >30 km crossing. A separate **sampled persistence** check requires ≥2 outside fixes and one outside fix 8–12h later, with no observed inside return during the following 12h.

**Supported result:** the source GPS often samples at sub-day intervals; the original 16h width is not the intrinsic source temporal resolution. In half the source cases the animal had already crossed the 30km boundary on the daily-centroid 'stationary' day. Timestamp aggregation can therefore bias the state-transition timing interpretation.

**Major scientific caution:** this is neither a validated migration onset time nor proof a bird decided to depart at that moment. A threshold crossing can represent a foraging excursion, and the 12-hour persistence criterion only describes sampled positions. Weather information actually perceived before the behavioral choice is still unknown. The apparent two speed outliers require source-quality inspection. One physical species study, 18 animal-years but only 9 distinct original animal identifiers overall, cannot be treated as 18 independent birds.

No new statistical or mechanistic evidence rescues the original vulture failure to replicate the stork solar-weather pattern.
