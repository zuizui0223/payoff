# PAYOFF-B shared 35 tag IDs: chronology diagnostic

2026-10-22. Source identity overlap was measured BEFORE opening any 2016
juvenile/adult autumn GPS movement. Exact original public CC0 reference
files: Rotics 2016 122 rows, Rotics 2018 36 rows, both published by
Movebank. Comparing four original fields found zero shared animal-ID,
animal-ring-ID or deployment-ID but 35 shared tag-ID values, appearing
in all 36 previous source reference rows.

An identical tag ID can reflect reuse of a physical tracker,
collisions in different identifier namespaces, or data migration
between Movebank Studies. It is NOT proof of the same animal. Compare
on/off deployment intervals within each shared tag to classify
definitely simultaneous versus sequential use when all dates exist.
Missing dates retain an unresolved status; no individual tag,
animal, calendar timestamp, study site or private GPS is disclosed.

Do not promote nonoverlap of source animal IDs to absolute ecological
independence; alternative name mappings and authors' original
published cohort descriptions may be necessary. The 2016 juvenile
versus adult mortality source has published prior art and is not
an untouched discovery of juvenile mortality.
