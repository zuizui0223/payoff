# PAYOFF-B: independent tracking source metadata screen — stage 2

Date: **2026-10-19**. Status: complete-corpus public-metadata discovery; **no animal outcome access**.

## Ecological target

The hypothesis is that remote forecast information and newly obtained
checkpoint information may have different behavioral effects, conditional on
remaining corrective opportunity. This is a question in full-annual-cycle
migration ecology; the V7R and V8 non-support results remain unchanged.

## Stage 1 source reconciliation

A public DataCite prefix search was run before stage 2: 2,080 DOI records,
including other publishers, 1,290 Movebank-publisher records, 453 parent DOI
records, 837 child/file DOI records, and 7 excluded MoveApps workflow parents.
The correct starting universe is **446 Movebank parent package candidates**,
not 2,080 independent studies. The stage-1 publisher/DOI audit retains the
full mixed-publisher inventory.

## Stage 2 protocol

- Re-enumerate the full 10.5441 DOI prefix and **fail closed** if any of the
  446 previously frozen parent candidates is missing or new.
- For each parent, attach public DataCite descriptive subjects, abstract text,
  linked publication DOIs, landing URL, file DOI counts and format *hints*.
- Keep all 446 rows. Never exclude a parent because it lacks English bird or
  migration keywords: titles may be Latin or not reflect actual sensors.
- Rank a 40-source **manual review queue** deterministically from text hints
  only; selection uses no animal arrival, tracking outcome, fitness or effect.
  This queue is not an analysis cohort or a representative sample.
- Prior PAYOFF-used Kölzsch 2015 Greenland, Svalbard and Barents DOI parents
  are flagged, as is the previously screened white-stork V4 source.
- Similar titles and shared paper DOIs are **possible** cohort-overlap flags;
  only individual/deployment IDs and source metadata can establish independence.
- A published CC0 / CC-BY identifier does not itself verify study/event-level
  access or waive Movebank data terms and attribution.

## Strict advancement gates

1. Review data and reuse licenses, source citation, file availability and
   the original article for each package.
2. Verify animal identity, taxon, deployment, timestamps, sensor type,
   data gaps and independently replicated annual migrations.
3. Establish actual stopover and route geometry from *individual* observations,
   not a nearest southward range-grid proxy.
4. Date each candidate local environmental cue **before** the focal decision;
   annual vegetation mid-greenup observed afterwards is not automatically
   an actionable cue.
5. Estimate remaining feasible response from independent animals/years rather
   than the focal animal's own observed adjustment.
6. Record incoming signed phase error, downstream speed/stopover choice,
   destination alignment, and separately observed survival/reproduction if any.
7. Prespecify a biological analysis using untouched cohorts and appropriate
   study/flyway/year sampling units. Fail closed when independence or a
   necessary mechanism proxy is missing.

These are **source eligibility gates**, not statistical thresholds selected
from favorable ecological results.
