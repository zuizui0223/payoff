# Temporal prior-art boundary for PAYOFF

PAYOFF does not claim that Floquet theory, periodic source-sink dynamics, nonautonomous cooperative systems, or dispersal-induced growth are new.

## Established temporal source-sink theory

Katriel (2022), **Dispersal-induced growth in a time-periodic environment**, develops time-periodic patch growth with dispersal using Floquet theory and characterizes conditions under which migration permits persistence even though isolated populations decline.

Benaim and collaborators have further developed dispersal-induced growth and decay in time-periodic patch systems, including reducible or asymmetric seasonal migration and principal Lyapunov exponent analyses.

Recent work continues to analyze time-periodic two-patch environments with asymmetric migration and the interaction of migration rate and oscillation frequency.

PAYOFF therefore does not claim to invent:

```text
principal Floquet exponents,
dispersal-induced growth,
dispersal-induced decay,
seasonal source-sink switching,
or temporal persistence generated by migration.
```

## PAYOFF temporal bridge

The architecture-specific contribution is the substitution

```text
r_j,l^D
= s_j,l L_j,l-K_j,l-eta_j,l
```

for rare differentiated architecture, with reciprocal rare-shared margin

```text
r_j,l^S
= -s_j,l L_j,l+K_j,l-eta_j,l.
```

These ecology-calibrated seasonal margins become the diagonal terms in established periodic patch operators.

## Registered common-forcing null

PAYOFF first separates the commuting case

```text
A(t)=A0+q(t)I.
```

There the temporal invasion exponent is exactly

```text
Lambda_temporal=Lambda0+mean(q),
```

so zero-mean fluctuations have no long-run effect.

This is standard commuting linear-systems mathematics used as a negative control.

## Registered noncommutativity gate

For two patches with fixed symmetric migration `m`, seasonal operators satisfy

```text
[A_a,A_b]
= m[(r_1,a-r_2,a)-(r_1,b-r_2,b)]
  [[0,1],[-1,0]].
```

Thus the common-shift null fails only when migration is nonzero and relative patch quality changes through time.

The exact two-patch Floquet implementation then compares

```text
Lambda_F
```

with the principal exponent of the time-averaged operator

```text
Lambda_avg.
```

The difference is a model-specific temporal-structure receipt; it is not itself a new Floquet theorem.

## Claim ceiling

Preferred:

> We use the common-additive temporal model as an exact null and then map season-specific architecture margins into a two-patch Floquet system when relative patch quality changes through time.

Avoid:

> We discover that temporal variation and dispersal can create population growth.

Preferred:

> In the declared PAYOFF example, the time-averaged operator predicts decline while the exact periodic operator predicts invasion, illustrating a known dispersal-induced-growth mechanism in architecture variables.

Avoid:

> Temporal variation generally favors trait differentiation.

Preferred:

> Seasonal noncommutativity requires both migration and changing patch contrast in the two-patch model.

Avoid:

> Noncommutativity always increases architecture growth.
