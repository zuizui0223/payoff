# PAYOFF-B：出発の暦日と季節位相は独立に識別できるか — 原データ事前構造ゲート

2026-11-22 ／ 原著公開データの探索的再解析 ／ **OUTCOME NOT OPENED**

## 結果：事前固定の構造ゲートが不成立

PR #413 で得た「同じシカが季節に対して遅く出る年ほど滞在が短い」という関連を、単なる暦日の遅さと区別できるかを検証するため、新しい季節位相係数を計算する**前に**同時説明変数の識別可能性を点検した。

- 出典：Ortega et al. (2023), *Nature Communications* 14:2008; DOI [10.1038/s41467-023-37750-z](https://doi.org/10.1038/s41467-023-37750-z)
- 公開 Source Data の SHA256：`2645420b74c8e2228eb555d14c755bba207c49ea72ecb2eff4c950892f743364`。GitHub Actions で再取得して厳密照合した。
- 親解析と同じ反復完全ケース：**100個体年・38個体・8観測年**。原データ152個体年から滞在データのある127個体年を確認し、真の0日（主標本11件）は保持し、欠測は0補完しない。
- 主モデルとして凍結：`Stopover_it ~ individual_FE + year_FE + DOY_Start_it + DFP_Start_it`。暦の出発日 `DOY_Start` と、植物のピークからの出発位相 `DFP_Start` の双方を同時に入れる。
- ただし、**事前固定したVIF上限10に対して、実測の共線性VIF = 16.536727**。従って結果は **NOT_ESTIMABLE** とした。

| 目的変数を開く前の診断 | 値 |
|---|---:|
| 共通個体・年固定効果を除いた暦日DOYの残差RMS | 12.825日 |
| 個体・年固定効果とDOYを除いたDFPの残差RMS | 3.344日 |
| 個体・年固定効果のみ除いたDFP残差RMS | 13.597日 |
| DFPとDOYの偏回帰VIF | **16.537** |

| 共同モデル残差自由度（識別可能な場合） | 54 |
| モデルの新規季節位相係数 | **推定せず** |

VIFから換算すると、個体・年固定効果を除いたDFPの残差変動の約 **93.95%** が、DOYの線形成分と重なる（同一回帰設計の代数的な換算）。この数値は情報の感知率、補償率、因果性の指標ではない。

## 科学的な解釈

前の同一個体固定効果の結果（出発位相10日あたり滞在 −6.89日、95%区間 −8.15〜−5.73日）は再解析結果として保持する。ただし、その関連を**季節位相への能動的な反応**として特定するには、暦日の効果を同時に分離する必要がある。今回の標本では分離条件を満たさなかった。

**これは「動物は植物の春を利用していない」と示した結果ではない。** また「暦だけがすべてを説明する」という係数検定でもない。強い説明変数の重なりにより、あらかじめ定めた精度で両者を識別できないという設計上の限界である。原著が示した移動途中の補償という観察事実は否定されない。

本検証は、親解析の肯定結果を見た後に立てた追加の探索的検定であり、独立した外部再現でも確認的な事前登録でもない。

## 次の本当に独立な実証へ必要なもの

同一個体または同じ研究系で、**出発暦日が近くても緑化ピークだけが変わる**（または逆）複数年・複数地点のデータ、さらに出発前に利用可能だった環境指標と、行動後の調整可能性が必要である。生物の将来情報を事後の緑化ピークから推定したことにはしない。

既存の公開シカ・原著結果を何度も条件変更して有意差探索することは行わない。VIF上限を16.54より上に緩める事後修正もしない。
