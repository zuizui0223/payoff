Preserve failures, no recoding or pseudocount. A source row count different from article triggers diagnostic rather than guessing. Use vial as unit, not 49,950 independent replicates.
2. Absolute consumer recruitment E[p,h,t] = mean number of P (emerged parasitoid adults) / 50 initially supplied host eggs. Preserve exact counts, cell n and zero values. Absolute host emergence in controls C[h,t] = H/50, and exposure vials H/50 separately. Report control-minus-exposed host emergence difference as a descriptive total suppression contrast (not actual infection/attack rate). Also calculate the authors' corrected denominator P/max(P,H,rounded control H) and its mean separately, zero denominator undefined not zero; don't confuse it with absolute P/50. No standardized metric pooled with theta.

Fixed ambient host performance under warming E[p,a,28]; hypothetical perfect host reassignment within the measured seven monocultures E[p,b,28]; ambient best E[p,a,24]. Report the observed warm upper envelope / ambient upper envelope and difference (ratio only when denominator positive). If ambient-to-warm loss negative, report fraction of that loss restored by hypothetical warm reassignment when denominator positive. Maximum estimated cell mean is a descriptive in-sample upper envelope of tested host options, not a true biological upper bound, independent prediction, observed behavioral switching or mixed-host manipulation.
