# PAYOFF-B: new independently sourced Egyptian vulture GPS timing limits

Date: 2026-10-22. Original threatened-species CC0 tracking source DOI 10.5441/001/1.385gk270. No event coordinates/IDs or exact dates are exported.

After the source was previously admitted (30 February–May northern three-day-stationary / two-day-move candidate events in 18 original animal-years), this timestamp-only source gate used the **first case per animal-year**, selected chronologically without examining environmental cues, and checked actual GPS sampling times. For each event, original code compared the last in-site (<30 km) fix on source stationary day with the first original following-day >30 km source fix. This interval is **GPS evidence bracketing**, NOT the moment of behavioral commitment.

| Source timing metric | Result |
| --- | ---: |
| Original deduplicated northward source candidates | 30 |
| Distinct animal-years with selected first source case | 18 |
| Last source-day GPS fix and first next-day outside fix within 24h | **15** |
| Time window <=12h | 5 |
| Time window <=6h | **0** |
| Source last-day fix already outside assumed site | 3 |
| Median width among <=24h cases | 16.00 h |
| 25–75% bracket width | 9.75–16.01 h |

The fixed >=10 animal-year <=24h source-sampling threshold passes, so a future exploratory physical-hourly meteorology audit would be technically possible. **But not a rigorous real-time information/decision test**, because none has an observed 6h or narrower GPS bracket and the original source provides no separately measured actual cue perception, fitness or feasible remaining route correction.

The independently tested pre-existing stork negative shortwave source association **did not replicate in this vulture source**: vulture within source 0.5° grid × year × month case-minus-stay solar anomaly +2.91 W/m², broad descriptive interval across zero, compared with stork −17.10 W/m². The new source weather may have different sampling times, habitats, geography and flying conditions, so this is not proof of a true between-species thermal ecology difference.

**Ecological next step:** no additional primary effect is justified in this archive without valid decision and independently available cue timestamps. Choose new, independent cohorts with simultaneous high-frequency telemetry + local weather/thermal observations + stagewise migration and downstream outcomes; don't retroactively change these thresholds. Original PAYOFF V7R/V8 and 53-season stork non-support remain intact.
