## Remaining submission blockers

### 1. Full bibliography

The manuscript currently contains a claim-boundary reference core rather than a
complete formatted reference list.

Need:

```text
all in-text citations represented
~40–50 references maximum if possible
consistent author–date style
```

### 2. Figure QA

Current synthesis figures exist and build in CI.

Need final checks:

```text
font readability at journal-column scale
panel labels
taxon scientific names
consistent lambda / innovation notation
colour-blind-safe interpretation without relying on colour alone
legends understandable independently of text
```

### 3. Double-anonymous repository

Do not link the public author-identifying GitHub repository from the blinded
main manuscript.

Prepare:

```text
anonymous reviewer code/data snapshot
private reviewer link
separate title page
```

### 4. Title page metadata

Separate title page must contain:

```text
authors
affiliations
one corresponding author
acknowledgements
funding
conflict of interest
contribution statement as appropriate
```

### 5. Cover letter

GEB requests a separate cover letter including a paragraph under 250 words
explaining why the paper matters to the journal's readers.

For the special issue, emphasize:

```text
individual biologging -> cross-taxon macroecological coordinate
prospective third-taxon test
universal constant rejected rather than forced
environmental information separated from phase retention
anthropogenic perturbation as actuation boundary
```

## Recommended title

Current preferred:

> **Migration timing as phase control: environmental information and phase retention across migratory taxa**

This foregrounds the general conceptual contribution without claiming a new
universal law.

## Editorial positioning

Do not sell the paper as:

```text
a paper about mule deer
a paper about geese
a new green-wave phenomenon
a universal optimal migration speed
a universal feedback law
```

Sell it as:

> **A biologging-enabled comparative framework that converts heterogeneous
> migration–phenology systems into a common phase-retention coordinate, then
> shows why similar timing precision can arise from different mixtures of
> environmental information and behavioral correction.**
