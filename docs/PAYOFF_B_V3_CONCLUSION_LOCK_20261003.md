## One-sentence ecological conclusion

> **Shared seasonal change can generate interaction mismatch because the clock
> that sets an organism's entry phase and the controller that corrects error
> afterward are distinct, and interacting organisms need not partition timing
> precision between those mechanisms in the same way.**

## One-sentence information conclusion

> **Environmental information can become more accurate while becoming less
> useful because the remaining opportunities to act on it are disappearing.**

## One-sentence robustness conclusion

> **Historical synchrony does not imply shared robustness: organisms can reach
> the same timing precision through different entry-versus-feedback
> architectures and respond differently when correction opportunity is lost.**

The robustness conclusion is Discussion/prospective theory, not a direct
natural-data conclusion.

## Main-text exact spine

### 1. Information-actionability balance

For the declared reduced model,

\[
N(t)=r(t)[Sq(t)-B]-C(t),
\]

so maximal information value can occur before maximal cue accuracy.

### 2. Entry-versus-correction architecture

A developmental/physiological timer determines entry phase; a post-entry
controller updates and corrects signed phase error.

### 3. Pairwise mismatch decomposition

In the declared serial witness,

\[
\Delta_n
=
(\lambda_1^n-\lambda_2^n)m_0
+
\frac{\lambda_1^n+\lambda_2^n}{2}\Delta_0.
\]

This separates controller-generated from timer-propagated mismatch.

### 4. Recovery boundary

Physical loss of actionability and strategic coordination failure are distinct
routes by which better environmental information may fail to restore
coordination.
