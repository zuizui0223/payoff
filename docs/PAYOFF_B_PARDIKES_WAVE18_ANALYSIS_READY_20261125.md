## Conditional analysis design (before original outcome acquisition)

The Wave 15 extraction plan names a factorial delay (0/2/4/6 days), temperature (24/28 C), food (low/high), parasitoid species (Asobara/Ganaspis), two monocultures and 50:50 mixture at the same total 100 initial host eggs, and five temporal blocks. These are the proposed design assumptions from the previous source screen, not yet confirmed against the actual CSV dictionaries and original raw rows. Fail closed if the final published experiment does not map to this layout; publish an outcome-blind schema amendment if needed, not an outcome-dependent exclusion. Different stage-specific or experiment-specific populations may not be combined just because field names match.

- Original files: both all.dat.*Nov24.csv and both README dictionaries. Use the exact byte sizes and SHA256 hashes already frozen in the Wave 17 source receipt. Script --check-source verifies all four before any normalization. This tests local user-supplied original bytes only.
- First inspect dictionaries, column identities, original allocation and controls, true vial/block grain, actual emerged adult parasitoid counts and introduced female denominators, initial egg numbers and host composition. Distinguish actual counts from repeated species rows, corrected denominators, simulation tables and derived proportions; retain valid zeros and unknowns separately. Never infer an animal count from a rounded derived rate, impute a missing denominator, or merge independently designed experiments. Require a separately reviewed normalization receipt and design eligibility. No raw-to-vial mapping written until source arrives.
- Conditional endpoint: mean actual emerged parasitoids per initially introduced female. Within each temperature × food × wasp stratum, average vial rates equally within block × delay × host condition, then average all five blocks equally. A mixture uses the same total host density as each single-host condition. The main candidate comparator is the equal-weight mean of the two monocultures at each delay; retain both individual monoculture comparisons as sensitivities. This tests composition-associated buffering, not observed behavioral host switching, pure richness, or independent information use. Primary admission still requires review of resource-relative timing, allocation, actual independently identified buffer, and source design.
- For each of the 2/4/6-day contrasts against zero delay, D=0/1, B=0 comparator/1 mixture, use W00/W10/W01/W11. Record r0=log(W10/W00), r1=log(W11/W01), theta=r1-r0, beta=log(W01/W00), eta=log(W11/W10), R=W11/W00. Retain additive difference W11-W10, W11-W00 and additive interaction even when a log ratio is undefined. A positive theta is attenuation only with detrimental reference perturbation; absolute benefit needs eta>0 (or W11>W10), and R describes residual absolute performance without arbitrary viability thresholds. No pseudocount for zero. If a zero mean makes a finite log estimate impossible, withhold that log estimate and consider a separately specified appropriate count likelihood only after source review.
- Require all five documented time blocks and complete factorial support; no deletion of a missing block or treatment to obtain a favorable contrast. Resample whole blocks jointly, enumerating 5^5=3125 resamples within each stratum. Shared block indices for every arm and all delay/host comparisons; retain joint log covariance per contrast and theta covariance across the nine contrasts in a stratum. Do not assume independence across strata or independent temperature room replication. Five blocks imply severe uncertainty; percentile ranges are conditional block-resampling sensitivity, not calibrated confidence intervals or sufficient evidence of causality. Undefined resampled logs suppress the corresponding interval/covariance rather than selectively retaining positive draws. No cross-study pooling, no sign-count test, no main-result admission on this preparation alone.
