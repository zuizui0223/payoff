# PAYOFF-B｜コウノトリ3群の実GPS原本に共通の観測日があるか

**2026-11-24｜公開CC0のオリジナルGPSデータの完全な行走査と、元イベントを出さない日付単位の集計。社会情報の受け取り・同所的行動・情報信頼性や適応度効果を測った研究ではない。**

## 1. 実測結果：3群の有効GPS観測が重なる日は519日

Bontekoe et al. (2023, *Proceedings B*, DOI [10.1098/rspb.2023.1268](https://doi.org/10.1098/rspb.2023.1268)) のオリジナル公開Movebank GPS ZIPから、**事前にサイズ・出典・CSVスキーマを固定した1ファイル／群**を原本MD5検証後、すべての行まで走査した。

| 公開データの群 | 元CSVイベント行 | UTC時刻＋タグID＋緯度経度が有効な行 | GPS観測のあるUTC日数 |
|---|---:|---:|---:|
| 対照 | 8,621,096 | 8,618,285 | 825 |
| 遅延 | 9,136,163 | 9,134,547 | 865 |
| 自然出発 | 9,266,108 | 9,264,443 | 573 |
| **選定3ZIP合計** | **27,023,367** | **27,017,275** | 延べ**2,263** |

有効行の基準は、ISO8601時刻をUTC日付として解釈可能、タグ文字列が非空、緯度・経度が有限数で物理的な範囲内、という**原データの技術的支持**だけである。GPSの高精度、鳥の生存、動的な社会接触、資源利用の良否を意味しない。

| 観測日についての検証 | 実測日数 |
|---|---:|
| **3群すべての選定ZIPに有効GPS記録があるUTC日** | **519** |
| 対照×遅延に共通の日 | 825 |
| 対照×自然出発に共通の日 | 519 |
| 遅延×自然出発に共通の日 | 522 |
| **3群の少なくともどれかに記録があるUTC日（和集合）** | **916** |
| 対照ZIPで1日内に2以上の異なるタグ文字列から記録がある日 | 805 |
| 遅延ZIPで同上 | 813 |
| 自然出発ZIPで同上 | 494 |

519日の内訳は**2020年207日・2021年312日**。これは受信装着日から推測した値ではなく、元GPSイベントの時刻から直接再計算したUTC日付の一致である。集計は[原本3群日別支持の結果](../data/payoff_b_stork_original_gps_day_overlap_result_20261124.json)と各群の元データ認証済み集計JSONに保存した。

**重要：この表の「共通」は同じ日付に記録が存在するという意味だけ。** 近くで飛んだこと、同じ時間帯に位置が取得されたこと、互いに見たこと、情報をやり取りしたこと、3群の別個体であることは意味しない。群間にタグ文字列の再出現があることを前[PR #419](https://github.com/zuizui0223/payoff/pull/419)で実測確認したため、特に同一鳥を自動的に識別しない。

## 2. 有効GPSの年支持と抜け

| 年 | 対照（有効GPS行） | 遅延（有効GPS行） | 自然出発（有効GPS行） |
|---|---:|---:|---:|
| 2019 | 2,606,431 | 1,637,543 | 0（**選定ZIPにはない**） |
| 2020 | 4,701,505 | 5,836,073 | 7,088,156 |
| 2021 | 1,310,349 | 1,660,931 | 2,176,064 |
| 2022 | 0（**選定ZIPにはない**） | 0（**選定ZIPにはない**） | 223 |

「0」は**今回は選択した1ZIPの有効GPS記録が0行**という意味であり、群全体のデータ欠落や鳥の不在を意味しない。元の公開アーカイブには遅延群でGPS ZIPが3ファイル、自然出発群で4ファイルあり、今回解析したのはそれぞれ最小サイズの**1本のみ**。まだ他の5ZIPは開いていない。

また、同じ年に記録された異なるタグ文字列数は、対照2019/2020/2021が9/12/5、遅延が5/11/4、自然出発2020/2021/2022が11/3/1。これは行数とは別の独立タグの上限的な記述で、装着イベントと実際の動物の独立性までは検証していない。

## 3. 認証と解析の方法

1. 元[PR #420](https://github.com/zuizui0223/payoff/pull/420)で、選定した3群それぞれの公開ZIPに実際の中央索引と**同じ26列のGPSイベント表**が含まれていることを確認し、ZIPサイズ・大きなCSVの展開サイズを固定した。
2. [原本GPS時系列の事前検証契約](../data/payoff_b_stork_original_gps_date_coverage_contract_20261124.json)をコミット後、公開DSpace `ORIGINAL`バンドルから再び元のビットストリームを取得した。**この工程のみ、公開CC0の大容量ZIPを一時的なGitHub Actions領域へ取得**。公開元のファイルサイズと原本MD5を全バイトで照合し、主CSVを終端まで展開してZIP内CRCも検査。個別GPS行を外部へ出さない。
3. すべてのCSV行で、UTC日付、緯度経度の数値範囲、非空タグ文字列を確認した。有効GPSの地理的な位置や元のタグ文字列をメモリ上の集計以外に保持せず、日別観測数・異なるタグ文字列数・年別件数だけを出力した。原本には時間的に無効な行は0、座標が不正な行は対照2,811、遅延1,616、自然出発1,665だった。
4. 独立に[共通UTC日の集計契約](../data/payoff_b_stork_gps_day_overlap_contract_20261124.json)を元GPS数値を開く前に凍結した。この検証では、公開済みの**派生した日別JSONだけ**を組み合わせ、3群共通日・群ペア共通日を計算し、日別・年別・ソース行の整合性を照合した。GPSの元座標や元タグ名は結合にも使わない。

## 4. 生態学の主張はまだここまで

今回の新しい資料上の進展は、**3群で実GPSの日単位の観測期間が重なるため、時間的な接触機会の検証へ進む最低限の実証データが存在する**ということ。まだ下記の条件は未確認。

- 同一日より細かい時刻の重なり（時間、分）、同じ位置にいた個体同士の近接距離、移動方向。
- 公開3群の研究を横断して同一個体を識別できる原資料のキー。Tag IDは再利用され、deployment IDの欠測もある。
- 決定**前**の情報として鳥が利用できる予測性能 `q`。近接タグ数は社会的な遭遇機会の一部にすぎず、qではない。
- 決定後に選択できる速度・滞在・ルートという修正可能性 `r`。残り距離とrを無条件に同一視しない。
- 予測性×行動余地×選択・適応度という独立・新規な関係。Bontekoe et al. 2023は出発遅延と経路・生存を、Brønnvik et al. 2024 (*Current Biology*, DOI 10.1016/j.cub.2024.03.052)は経験に伴う他個体密度への経路選好の変化を既に報告している。

**本研究の結果はGPSソースの時系列支持であり、社会情報による適応的行動の証明でも新規な因果効果でもない。** 次の許容される検証は、元データの個体IDを正しく扱い、3群共通の**同じ時間帯・地理的に近い記録が存在するか**を保守的に判定すること。元の資料でこの条件が満たされなければそこで止め、情報利用の物語へ結論を昇格しない。

`main`および凍結原稿は変更しない。eBird/TinyFish未使用。
