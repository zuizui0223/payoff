# PAYOFF-B whole-animal/year sensitivity for complete GPS at-risk weather

Registered 2026-10-22, AFTER seeing the original complete physical weather
source contrasts. This analysis is therefore explicitly POST-OUTCOME
ROBUSTNESS, NOT a new preregistered ecological hypothesis test.

All three original MD5-pinned published CC0 source datasets and complete
5,509 three-day stationary source risk opportunities are reproduced.
The same 809 unique 0.5-degree grid-month-year daily NASA POWER queries
are made; riskday environmental anomalies use only UTC dates anchor
minus one through minus eight. There is NO model tuning to effect sign.

The source estimand remains the mean (northward-labelled days minus
continuing-stay-labelled days) of physical weather anomalies within
grid×calendar-year×month strata containing BOTH classes, weighted by case
count within each observed overlap stratum. Unmatched cases are never
silently converted to controls.

Sensitivity 1: 1,000 fixed-seed (20261022) whole-ANIMAL block bootstrap
resamples complete original source histories, including all source years.
For each draw the same grid×year×month contrast is recomputed; exclude
replicates with <10 overlap strata or <25 case-day weights. Disclose the
number of invalid replicates. Report a 95% *DESCRIPTIVE* percentile
interval only if >=90% of 1,000 draws remain estimable. This accounts
for within-animal serial dependence better than naive GPS-day bootstrap
but NOT correlations between independent birds in the same weather
cell or migration corridor.

Sensitivity 2: remove each observation calendar year in turn; recompute
the original contrast without changing any model parameters. Report each
remaining source contrast and overlap case/stratum count. It is not
an independent validation on an untouched environmental dataset.

Interpretation ceiling: original weather contrasts, uncertainty and
cross-clade heterogeneity are exploratory source records; neither
behavioural signal perception, thermal updraft, route feasible options,
destination phenology, Darwinian fitness benefit nor PAYOFF-B evolutionary
game-theoretic mechanism is established by these observational data.
