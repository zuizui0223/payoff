# Two-patch heterogeneity can reverse a coordination game

This note isolates a sharp special case of the environment-mosaic model.

Consider two unit-coupled patches with one common positive frequency-feedback coefficient

```text
eta>0
```

and reference static architecture gaps

```text
phi_1,
phi_2.
```

Let

```text
phi_bar=(phi_1+phi_2)/2,
Delta_phi=phi_1-phi_2.
```

Choose the common environmental shift so that the landscape mean static gap is zero. Equivalently evaluate the landscape at the environmental midpoint

```text
phi_1'=+Delta_phi/2,
phi_2'=-Delta_phi/2.
```

This is the spatial analogue of evaluating the homogeneous game at the static architecture crossing `phi=0`.

---

## Theorem 1 — reciprocal invasion exponent at the landscape midpoint

Rare-D local margins are

```text
r_D=(+Delta_phi/2-eta,
     -Delta_phi/2-eta).
```

Rare-S margins are the reversed vector

```text
r_S=(-Delta_phi/2-eta,
     +Delta_phi/2-eta).
```

By symmetry, their principal spatial invasion exponents are identical:

```text
Lambda_D(m)=Lambda_S(m)=Lambda_mid(m),
```

with

```text
Lambda_mid(m)
= -eta-m
  + sqrt[(Delta_phi/2)^2+m^2].
```

### Proof

Use the exact two-patch principal eigenvalue

```text
Lambda_+
= 1/2[r_1+r_2-2m
      +sqrt((r_1-r_2)^2+4m^2)].
```

For either reciprocal margin vector,

```text
r_1+r_2=-2eta,
r_1-r_2=+-Delta_phi.
```

Substitution gives the result. QED.

---

## Corollary 1.1 — environmental heterogeneity can overcome positive frequency coordination

At zero migration,

```text
Lambda_mid(0)
= |Delta_phi|/2-eta.
```

Therefore

```text
|Delta_phi|>2eta
```

implies

```text
Lambda_D(0)>0
and
Lambda_S(0)>0.
```

So although each local game has positive frequency dependence, sufficiently strong environmental contrast makes both landscape-level monomorphic architecture states invasible when patches are weakly coupled.

This is reciprocal spatial invasion generated by habitat heterogeneity, not by negative frequency dependence.

If

```text
|Delta_phi|<2eta,
```

then neither architecture can invade the opposite monomorphic landscape at zero migration at the mean static crossing.

---

## Theorem 2 — exact migration-driven switch from reciprocal invasion to coordination

Assume

```text
eta>0,
|Delta_phi|>2eta.
```

The equation

```text
Lambda_mid(m)=0
```

has the unique positive solution

```text
m_switch
= [Delta_phi^2-4eta^2]/(8eta).
```

Hence

```text
0 <= m < m_switch
-> Lambda_D>0 and Lambda_S>0
-> reciprocal spatial invasion;

m = m_switch
-> both reciprocal invasion exponents are zero;

m > m_switch
-> Lambda_D<0 and Lambda_S<0
-> mutual spatial non-invasion / coordination.
```

### Proof

Set

```text
sqrt[(Delta_phi/2)^2+m^2]
= eta+m.
```

Both sides are positive. Squaring gives

```text
Delta_phi^2/4
= eta^2+2eta m,
```

hence

```text
m
= [Delta_phi^2-4eta^2]/(8eta).
```

The assumed contrast condition makes the root positive. The principal exponent decreases monotonically with migration under heterogeneous local margins, so the crossing is unique. QED.

---

## Corollary 2.1 — dimensionless form

Define environmental contrast relative to coordination strength:

```text
chi
= |Delta_phi|/(2eta).
```

Then reciprocal invasion at low migration requires

```text
chi>1.
```

The migration threshold becomes

```text
m_switch/eta
= (chi^2-1)/2.
```

Thus the two controlling dimensionless quantities are

```text
environmental architecture contrast / frequency-feedback strength,

migration / frequency-feedback strength.
```

---

## Corollary 2.2 — translate directly to SCH/BALANCE/BITA quantities

Because

```text
phi_j=s_jL_j-K_j,
```

the contrast condition is

```text
|(s_1L_1-K_1)-(s_2L_2-K_2)|
> 2eta.
```

The exact migration switch is

```text
m_switch
=
{[(s_1L_1-K_1)-(s_2L_2-K_2)]^2-4eta^2}
/(8eta).
```

This is a direct spatial prediction from patch-specific conflict, dimensional recovery, architecture cost, and frequency feedback.

---

## Interpretation

The nonspatial coordination story is

```text
eta>0
-> rare alternatives are disfavored near the static crossing.
```

The two-patch environment-mosaic story adds

```text
large enough patch contrast
-> one patch is a D source while the other is an S source
-> both monomorphic landscapes become invasible;

migration increases
-> source advantages are diluted across the opposite sink
-> reciprocal invasion disappears
-> the underlying positive-frequency coordination barrier re-emerges.
```

So habitat heterogeneity and frequency dependence can oppose one another, and migration tunes which mechanism dominates.

This does not by itself prove a stable nonlinear coexistence equilibrium below `m_switch`; reciprocal invasion is a local criterion around the two monomorphic landscape states.
