# PAYOFF transport principle

PAYOFF can now be compressed into one architecture-to-population map:

> **Ecological conflict generates a fitness-valued architecture landscape; population processes transport pairwise contrasts on that landscape into invasion, fixation, occupancy, spatial growth, temporal growth, and architecture-state evolution without redefining the original conflict receipt.**

The original binary chain

```text
L -> R=sL -> phi=R-K
```

remains an exact special case, but the more general architecture-level chain is

```text
shared functional conflict
        |
        v
conflict load L
        |
        v
candidate architecture a
        |
        v
recovered conflict loss R(a)
        |
        v
architecture cost K(a)
        |
        v
intrinsic optimized payoff
b(a)=R(a)-K(a)
        |
        v
pairwise canonical game coordinates
(phi_ab,eta_ab)
        |
        +--> deterministic invasion
        +--> finite fixation
        +--> mutation-selection occupancy
        +--> spatial spectral growth
        +--> temporal Floquet growth.
```

The same architecture landscape can also evolve internally through continuous coupling changes, edge release, topology mutation, and branching.

This document records what is transported, what is transformed, and what remains model-specific.

---

# Part I — generating the architecture landscape

## Transport A0 — shared conflict load

SCH supplies the one-coordinate conflict geometry.

For the registered two-function quadratic model,

```text
L
=[ab/(a+b)](theta1-theta2)^2.
```

For `n` functions, the shared conflict load is weighted disagreement around the common optimum.

`L` is a within-organism loss receipt. It is not yet a population-game payoff.

---

## Transport A1 — architecture recovery

A candidate architecture `a` changes how much of the shared conflict can be recovered before architecture cost.

Define

```text
R(a)
= shared optimized loss
  - optimized loss under architecture a.
```

For the registered two-coordinate residual-coupling model,

```text
R=sL.
```

For a connected many-function coupling graph with global strength `lambda`,

```text
R(lambda)
=L-D_lambda*.
```

`R(lambda)` decreases continuously and strictly with integration strength when function-specific optima differ.

For edgewise coupling vector `c`, recovery is generated by phenotype optimization under the full coupling topology.

---

## Transport A2 — costed intrinsic architecture payoff

Assign architecture cost

```text
K(a).
```

Relative to a reference shared architecture, define intrinsic optimized architecture payoff

```text
b(a)
=R(a)-K(a).
```

For the original binary shared/differentiated contrast,

```text
b(S)=0,
b(D)=R-K,
```

so

```text
phi=b(D)-b(S)=R-K=sL-K.
```

Thus the familiar scalar `phi` is the pairwise intrinsic contrast generated by the broader architecture payoff landscape.

# Part II — architecture state itself can evolve

## Transport A3 — continuous recovery coordinate

Along a one-dimensional release path where `R(lambda)` is monotone, use recovered loss itself as the architecture coordinate:

```text
r=R(lambda) in [0,L].
```

Let cost be a smooth function

```text
C(r).
```

Intrinsic payoff is

```text
b(r)=r-C(r).
```

An interior intrinsic architecture satisfies the marginal condition

```text
C'(r*)=1.
```

This asks:

> Where does architecture optimization settle before frequency-dependent ecology is added?

For quadratic cost

```text
C(r)=c1*r+(kappa/2)r^2,
```

one obtains

```text
r*=clip[(1-c1)/kappa,0,L].
```

This gives shared, partial-modularity, and full-differentiation intrinsic phases.

---

## Transport A4 — continuous architecture branching

Add symmetric architecture-distance feedback

```text
H(r,q)=-gamma(r-q)^2.
```

The monomorphic selection gradient remains

```text
1-C'(r).
```

so symmetric mismatch feedback does not move the first-order singular architecture.

At an interior singular `r*`, mutant curvature is

```text
-C''(r*)-2gamma.
```

Hence the local branching threshold is

```text
gamma_branch
=-C''(r*)/2.
```

For quadratic cost this becomes

```text
gamma=-kappa/2.
```

Thus architecture location and architecture diversification are controlled by different receipts:

```text
location
<- marginal cost C'(r*),

branching susceptibility
<- local cost curvature C''(r*).
```

For the declared quadratic global potential game, strong dissimilarity feedback produces a protected mixture of the shared and fully differentiated endpoints.

---

## Transport A5 — edgewise modularization pressure

Give each functional coupling edge `e=(i,j)` its own coupling strength `c_e`.

After phenotype optimization,

```text
partial D*/partial c_e
=(x_i*-x_j*)^2.
```

Therefore squared optimized disagreement across an edge is its exact marginal coupling penalty.

Using decoupling amount `d_e`,

```text
partial R/partial d_e
=(x_i*-x_j*)^2.
```

Against a differentiable architecture cost `K(d)`, an interior edge satisfies

```text
(x_i*-x_j*)^2
=partial K/partial d_e.
```

This is an edge-level architecture-selection receipt before population frequency dependence.

---

## Transport A6 — continuous couplings can generate discrete topology

In the registered quadratic network model, recovery is convex in edgewise decoupling.

With additive linear decoupling cost,

```text
Phi(d)
=R(d)-sum_e k_e d_e
```

is convex on the coupling box.

Therefore at least one global optimizer is a vertex:

```text
d_e in {0,c_e^0}.
```

So continuously allowed coupling strengths can endogenously generate a retain/release modular topology under the declared cost geometry.

This bang-bang result is model-specific; sufficiently convex architecture cost can instead stabilize graded couplings.

---

## Transport A7 — local accessibility differs from global architecture payoff

For one released edge with linear unit cost `k`, define

```text
k_local=R'(0),
k_global=R(dmax)/dmax.
```

Convex recovery gives

```text
k_local<=k_global.
```

Therefore

```text
k_local<k<k_global
```

is a finite-jump architecture barrier:

```text
small release selected against,
complete release higher payoff.
```

For the original two-function quadratic model,

```text
k_local=s0^2 Delta^2,
k_global=s0 Delta^2,
```

with barrier width

```text
s0(1-s0)Delta^2.
```

This is the architecture-construction analogue of PAYOFF's recurring distinction between static advantage and invasion/accessibility.

# Part III — canonical population coordinates for architecture pairs

## Transport P0 — any symmetric architecture pair has canonical PAYOFF coordinates

Take any symmetric pairwise payoff matrix

```text
          S      T
S         a      b
T         b      d.
```

Define

```text
phi_ST
=(d-a)/2,

eta_ST
=(a+d-2b)/2.
```

After subtracting a common payoff constant, the pair is exactly

```text
          S              T
S         0          phi-eta
T      phi-eta          2phi.
```

Thus

```text
Delta_ST(p)
=phi_ST+eta_ST(2p-1).
```

The PAYOFF pair coordinates are therefore a canonical local language for every symmetric architecture game.

---

## Transport P1 — intrinsic payoff plus symmetric ecological feedback

For a symmetric multi-architecture decomposition

```text
A_ij=b_i+b_j+H_ij,
```

pair canonicalization gives

```text
phi_ij
=b_j-b_i+(H_jj-H_ii)/2,
```

and

```text
eta_ij
=(H_ii+H_jj-2H_ij)/2.
```

If same-type feedback is equal,

```text
H_ii=H_jj,
```

then the canonical `phi_ij` equals the intrinsic architecture payoff difference.

---

## Transport P2 — topology-distance special case

For vertex coupling topologies represented by binary edge-release vectors, define weighted distance

```text
q(S,T)
=sum_e w_e(s_e-t_e)^2.
```

With

```text
H_ST=-gamma q(S,T),
H_SS=H_TT=0,
```

the pair coordinates reduce to

```text
phi_ST=b_T-b_S,
eta_ST=gamma q(S,T).
```

Thus every topology pair inherits the full binary PAYOFF invasion/fixation classification.

# Part IV — transporting pair coordinates through population processes

## Transport 1 — deterministic reciprocal invasion

For a pair with canonical coordinates `(phi,eta)`,

```text
Delta(p)=phi+eta(2p-1).
```

Rare-invasion margins are

```text
I_T=phi-eta,
I_S=-phi-eta.
```

Neutral surfaces are

```text
phi=+eta,
phi=-eta.
```

Hence static architecture difference and rare invasion are different estimands.

---

## Transport 2 — finite-population fixation

For the declared self-excluding exponential Moran process,

```text
rho_T/rho_S
=exp[beta(N-2)phi].
```

The interaction coordinate `eta` changes absolute fixation probabilities but cancels from the reciprocal ratio.

Under weak selection,

```text
rho_T>1/N
iff
3phi>eta.
```

Thus deterministic invasion and stochastic fixation transport the same pair coordinates through different thresholds.

---

## Transport 3 — symmetric rare-mutation stationary abundance

For any finite symmetric architecture game, define self-play score

```text
u_i=A_ii/2.
```

For pair `i,j`, canonicalization gives

```text
phi_ij=u_j-u_i.
```

With connected symmetric rare mutation, the monomorphic substitution chain has exact stationary weights

```text
Pi_i
propto
exp[beta(N-2)u_i].
```

Off-diagonal ecology affects invasion, coexistence, absolute fixation, and substitution kinetics but cancels from these stationary monomorphic weights.

For a zero-diagonal architecture-feedback decomposition,

```text
u_i=b_i,
```

so

```text
Pi_i
propto
exp[beta(N-2)b_i].
```

This is a weak-mutation monomorphic result, not the full recurrent-mutation population stationary law.

---

## Transport 4 — topology mutation accessibility

For single-edge topology mutation, long-run stationary preference does not determine accessibility.

Define the best single-edge path bottleneck from topology `S` to `G`:

```text
m*(S,G)
=max_P min_{U in P} b_U.
```

Intrinsic valley depth is

```text
B(S->G)
=max[0,b_S-m*(S,G)].
```

Thus a globally high-payoff topology can receive high stationary weight while every single-edge path toward it crosses a lower-payoff topology.

This separates

```text
stationary abundance
from
transition kinetics / accessibility.
```

---

## Transport 5 — regular-graph local competition

Under the declared Ohtsuki-Nowak weak-selection pair approximation for the original PAYOFF matrix,

```text
phi_k=[k/(k-2)]phi,
eta_k=eta.
```

The graph preserves the sign of `phi` while changing its magnitude relative to interaction curvature.

## Transport 6 — heterogeneous spatial landscape

Patch-specific pair receipts are

```text
phi_j,
eta_j.
```

Rare-type local margins form a vector

```text
r_j=phi_j-eta_j
```

for the chosen invasion direction.

Conservative migration transports that vector through

```text
A=diag(r)-mL_G.
```

The population-level receipt is

```text
Lambda
=lambda_max(A).
```

For connected undirected migration,

```text
max_j r_j
=Lambda(0)
>=Lambda(m)
->mean_j r_j
```

as migration becomes strong.

---

## Transport 7 — common environmental shift

If every local architecture gap receives the same additive environmental change,

```text
phi_j(e)=phi_j0+alpha(e-e0),
```

then the spatial invasion spectrum shifts rigidly:

```text
Lambda_D(e,m)
=Lambda_D(e0,m)+alpha(e-e0).
```

Reciprocal invasion receives the opposite shift.

---

## Transport 8 — common temporal forcing

If temporal variation is a common scalar forcing,

```text
A(t)=A0+q(t)I,
```

then

```text
Lambda_temporal
=lambda_max(A0)+mean(q).
```

Zero-mean common forcing has no extra temporal premium.

---

## Transport 9 — noncommuting temporal structure

When relative patch quality changes through time, seasonal invasion operators need not commute.

For the registered symmetric two-patch two-season model,

```text
Lambda_F
=lambda_max(A_bar)+P_temp,
```

with

```text
P_temp>=0.
```

The temporal premium vanishes at commuting gates and is positive otherwise.

For anti-phase source switching, `P(m)` has one exact finite migration maximum and can overcome a positive-frequency coordination barrier.

At reciprocal architecture edges,

```text
Lambda_T=phi_bar-eta+P,
Lambda_S=-phi_bar-eta+P,
```

so temporal source switching acts like the edge-level replacement

```text
eta_eff=eta-P.
```

This is an invasion-edge identity, not a global nonlinear-game equivalence.

# Part V — what is invariant, and what is not?

## Invariant upstream biology

Downstream population models do not redefine:

```text
functional conflict L,
recovery R(a),
architecture cost K(a),
intrinsic architecture payoff b(a).
```

Those quantities should be estimated upstream on one common fitness scale whenever possible.

## Pairwise population coordinates

For symmetric games, `(phi,eta)` are canonical pairwise coordinates.

But canonical population `phi` equals intrinsic payoff difference only when same-type feedback is equal across the pair.

## Different downstream estimands

The framework distinguishes:

```text
intrinsic architecture optimum,
architecture branching,
edge-release accessibility,
pairwise rare invasion,
finite fixation,
rare-mutation monomorphic occupancy,
spatial spectral growth,
temporal Floquet growth.
```

They are deliberately not collapsed into one generic "architecture threshold."

# Cross-scale falsification strategy

The strongest design estimates different layers independently.

```text
SCH
-> conflict load L

BITA / architecture manipulation
-> recovery R(a)

architecture assay
-> cost K(a)
-> intrinsic b(a)

frequency experiment
-> pairwise interaction curvature eta

finite / spatial / temporal experiment
-> freeze population-process parameters
-> predict downstream invasion/fixation/occupancy.
```

For continuous architecture evolution, independently estimate the cost curve:

```text
C'(r*)
```

and

```text
C''(r*)
```

to predict intrinsic location and branching susceptibility.

For edgewise topology, independently reconstruct edge pressures

```text
(x_i*-x_j*)^2
```

and topology payoffs before fitting population frequencies.

A downstream mismatch is scientifically useful: it localizes failure to the recovery geometry, cost model, interaction kernel, mutation process, spatial model, or temporal forcing assumption.
