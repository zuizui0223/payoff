# PAYOFF-B persistent-state two-clock extension

Date: **2026-10-03**  
Status: **post-hoc post-freeze extension formulated after the frozen mule-deer serial-handoff audit; frozen GEB V2 unchanged**

## 1. Why pure handoff is not enough

The serial baseline separates:

1. a developmental/physiological clock that determines entry phase \(e_0\);
2. a post-entry decision controller that propagates/corrects that phase through
   \(\lambda\).

A frozen mule-deer test of the strongest Markov version did not support the
prediction that March IFBFat adds no downstream information once
\(DFP_{Start}\) is included. In the primary clustered model,
\(DFP_{Start}\)'s interval crossed zero while IFBFat retained a conditional
association with \(DFP_{End}\); after within-year centering, both were
unresolved.

That result cannot establish physiological carryover, but it shows that a model
forcing the entry-clock state to disappear immediately after entry is too
restrictive as a default.

## 2. Persistent physiological state

Let \(s_k\) denote a physiological state present at entry and retained after
entry according to

\[
s_{k+1}
=
\rho s_k.
\]

Let phase evolve as

\[
e_{k+1}
=
\lambda e_k+\psi s_k.
\]

Here

- \(\lambda\) is post-entry phase retention generated by information,
  opportunity and decision control;
- \(\rho\) is persistence of the physiological state;
- \(\psi\) is the direct effect of that state on subsequent phase.

The pure handoff is the nested special case

\[
\psi=0.
\]

## 3. Exact persistent-state solution

Because

\[
s_k=\rho^k s_0,
\]

after \(n\) checkpoints,

\[
\boxed{
e_n
=
\lambda^n e_0
+
\psi s_0 H_n(\lambda,\rho),
}
\]

where

\[
H_n(\lambda,\rho)
=
\sum_{j=0}^{n-1}
\lambda^{n-1-j}\rho^j.
\]

For \(\lambda\ne\rho\),

\[
\boxed{
H_n
=
\frac{\lambda^n-\rho^n}
{\lambda-\rho}.
}
\]

For \(\lambda=\rho\),

\[
\boxed{
H_n
=
n\lambda^{n-1}.
}
\]

The final phase therefore contains

\[
\text{propagated entry error}
+
\text{persistent physiological carryover}.
\]

## 4. Conditional downstream state effect

Under the ideal structural model,

\[
e_n
=
\lambda^n e_0
+
\psi H_n s_0.
\]

Therefore the structural coefficient of \(s_0\) conditional on perfectly
measured \(e_0\) is

\[
\boxed{
B_s
=
\psi H_n.
}
\]

An observed regression coefficient is not automatically \(B_s\). Measurement
error in entry phase, unmeasured annual drivers and selection can all leave
residual association with \(s_0\).

The current mule-deer result is therefore motivation only, not a parameter
estimate of \(\psi\) or \(\rho\).

## 5. Variance decomposition

Let

\[
A=\lambda^n,
\qquad
B=\psi H_n.
\]

Then

\[
e_n=Ae_0+Bs_0
\]

and

\[
\boxed{
\operatorname{Var}(e_n)
=
A^2\operatorname{Var}(e_0)
+
B^2\operatorname{Var}(s_0)
+
2AB\operatorname{Cov}(e_0,s_0).
}
\]

Thus downstream phase variance can be reduced by feedback while still
retaining a physiological-state signature. A phase-variance funnel therefore
does not, by itself, prove that the entry-clock state has disappeared.

## 6. Pairwise interaction mismatch gains a third component

For actor \(i\),

\[
e_{i,n}
=
\lambda_i^n e_{i,0}
+
\psi_i s_{i,0}H_{i,n}.
\]

Hence

\[
\boxed{
\Delta_n
=
\underbrace{
\lambda_1^n e_{1,0}
-
\lambda_2^n e_{2,0}
}_{\text{serial entry + controller component}}
+
\underbrace{
\psi_1s_{1,0}H_{1,n}
-
\psi_2s_{2,0}H_{2,n}
}_{\text{persistent-state component}}.
}
\]

The earlier serial theorem is recovered when both \(\psi_i=0\).

## 7. Three biological architectures

### Pure entry clock

\[
\psi=0.
\]

Physiological state matters only through entry phase.

### Persistent physiological state

\[
\psi\ne0,\qquad |\rho|<1.
\]

The state gradually loses influence after entry.

### Long-lived state

\[
\rho\approx1.
\]

A pre-entry physiological condition can affect later phase across many
checkpoints even though it does not gate the signed feedback gain.

This is distinct from H2 concurrent gating. H2 concerns whether physiological
state changes the **slope of action on signed phase**; persistent carryover
concerns an additional state-dependent phase contribution.

## 8. Relation to the mule-deer results

The current mule-deer evidence has four pieces:

1. March IFBFat predicts migration-start timing in the conservative readiness
   subset;
2. signed start phase predicts post-entry speed and stopover after controlling
   for IFBFat;
3. IFBFat does not detectably moderate those signed actuator slopes in the
   frozen H2 proxy test;
4. the frozen pure-handoff downstream-phase test is not compatible with the
   strongest entry-only Markov prediction.

Together these motivate distinguishing entry timing, persistent physiological
state and signed decision feedback.

Because this extension was formulated after item 4 was known, those mule-deer
data cannot be used to validate the persistent-state theory.

## 9. Prospective empirical test

A direct test needs repeated physiological measurements after entry.

Measure

\[
s_0,s_1,\ldots,s_n
\]

alongside

\[
e_0,e_1,\ldots,e_n
\]

and actions.

The persistent-state model predicts:

1. physiological state should show a measurable decay/persistence parameter
   \(\rho\);
2. conditional on previous phase, state should predict next phase through
   \(\psi\);
3. signed phase should independently predict corrective actions through the
   decision controller;
4. a model with measured state persistence should outperform a pure Markov
   phase-only handoff on held-out downstream phase.

## 10. Novelty boundary

State-space models with persistent covariates and linear forcing are standard.

PAYOFF-B should claim only the ecological synthesis:

> **a physiological timing system can determine entry timing and still leave a
> persistent state signature after control has passed to an
> information-dependent decision system.**

The current natural evidence motivates this extension but does not confirm it.
