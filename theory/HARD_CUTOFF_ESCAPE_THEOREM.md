# Hard-cutoff escape theorem for a shared resident

This note gives one exact continuous finite-jump result for the bounded
architecture-interaction extension.

It is deliberately narrow: resident architecture `r=0`, quadratic intrinsic
payoff, negative mismatch feedback, and a hard interaction cutoff.

Implementation:

```text
src/bounded_interaction_theory.py
```

---

## Setup

Let

```text
b(r)=alpha r-(kappa/2)r^2,
alpha>0,
kappa>=0.
```

A monomorphic shared resident at `0` produces bounded interaction

```text
H_epsilon(r,0)
=-gamma r^2 1{r<=epsilon}.
```

For `gamma<0`, mismatch is rewarded while the mutant remains inside the
interaction neighbourhood.

Therefore

```text
p_in(r)
=alpha r-(kappa/2+gamma)r^2,
0<=r<=epsilon,
```

whereas immediately outside the interaction radius

```text
p_out(r)
=alpha r-(kappa/2)r^2.
```

At the interface,

```text
p_out(epsilon)-p_in(epsilon)
=gamma epsilon^2<0.
```

So leaving the interaction neighbourhood causes a downward payoff jump.

---

## Theorem HCE1 — exact escape-jump infimum

Assume:

1. `p_in(r)` is strictly increasing on `[0,epsilon]`;
2. `p_out(epsilon)>0`.

Because `gamma<0`,

```text
0 < p_out(epsilon) < p_in(epsilon).
```

Hence there is a unique

```text
x* in (0,epsilon)
```

such that

```text
p_in(x*)=p_out(epsilon).
```

Every state below `x*` is reachable from the shared resident by arbitrarily
small strictly-uphill steps. A jump from a point just below `x*` to a point just
outside `epsilon` is strictly uphill. Conversely, any jump smaller than
`epsilon-x*` cannot cross the interface from an uphill-reachable source to an
outside state with higher payoff.

Therefore the infimum finite jump required to escape the hard-cutoff ridge is

```text
delta_escape
=epsilon-x*.
```

Strict continuum accessibility requires

```text
delta > delta_escape;
```

at exact equality the limiting comparison is neutral.

### Closed form

Write

```text
A=kappa/2+gamma,
B=alpha epsilon-(kappa/2)epsilon^2.
```

If `A != 0`,

```text
x*
=
[alpha-sqrt(alpha^2-4 A B)]/(2 A).
```

If `A=0`,

```text
x*=B/alpha.
```

Then

```text
delta_escape=epsilon-x*.
```

## Interpretation

The result exposes a new distinction inside the declared PAYOFF extension:

```text
local disruptive selection exists
!=
a locally evolving lineage can cross the interaction-range interface.
```

For this hard-cutoff model, the interaction radius itself can create an
**architecture accessibility barrier** even though the underlying intrinsic
payoff `b(r)` is smooth and concave.

This is separate from the earlier convex-recovery modularization barrier:

```text
DISCONTINUOUS_MODULARIZATION_BARRIER
-> barrier generated by recovery/cost geometry;

HARD_CUTOFF_ESCAPE_THEOREM
-> barrier generated by finite-range ecological interaction.
```

They can in principle coexist in a richer architecture landscape.

---

## Claim boundary

HCE1 does not claim that real biological interaction kernels have hard cutoffs.
A smooth bounded kernel can remove the literal payoff discontinuity. The useful
scientific question is whether a finite interaction range still creates a
finite accessibility bottleneck after the hard cutoff is replaced by a smooth
kernel; that is a robustness problem, not assumed here.
