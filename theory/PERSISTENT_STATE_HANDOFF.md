# PAYOFF-B persistent-state serial handoff

Date: **2026-10-03**  
Status: **post-hoc extension formulated after the mule-deer pure-handoff audit; frozen GEB V2 unchanged**

## 1. Why a pure handoff can fail

The simplest serial architecture assumes:

\[
\text{physiological clock}
\rightarrow
\text{entry phase }e_0
\rightarrow
\text{decision controller},
\]

with no further physiological contribution after entry.

The frozen mule-deer audit did not support that strict Markov-style handoff.
In the conservative 62-animal-year subset,

\[
DFP_{\rm End}
\sim
DFP_{\rm Start}
+
IFBFat,
\]

gave:

- conditional \(DFP_{\rm Start}=+0.215\), cluster CI
  \([-0.008,+0.422]\);
- conditional IFBFat \(=-2.52\), cluster CI
  \([-5.81,-0.45]\).

After within-year residualization both terms were unresolved.

The licensed inference is therefore only that a pure entry-only handoff is not
supported by the primary clustered test.  It does not establish persistent
physiology.

## 2. Persistent-state extension

Let \(s_k\) denote a physiological or energetic state that survives entry.

Assume

\[
\boxed{
s_{k+1}
=
\rho s_k
}
\]

and

\[
\boxed{
e_{k+1}
=
\lambda e_k
+
\beta s_k
+
w_k.
}
\]

Here:

- \(\lambda\) = post-entry phase retention generated by the decision-control
  system;
- \(\rho\) = persistence of physiological state;
- \(\beta\) = direct effect of that state on downstream phase;
- \(w_k\) = new environmental/behavioral innovation.

The decision clock and physiological state remain distinct even when both
affect downstream timing.

## 3. Exact zero-innovation solution

With \(w_k=0\),

\[
s_k
=
\rho^k s_0.
\]

After \(n\) checkpoints,

\[
\boxed{
e_n
=
\lambda^n e_0
+
\beta s_0
H_n(\lambda,\rho)
}
\]

where

\[
H_n(\lambda,\rho)
=
\sum_{j=0}^{n-1}
\lambda^{n-1-j}\rho^j.
\]

For \(\lambda\ne\rho\),

\[
\boxed{
H_n
=
\frac{\lambda^n-\rho^n}
{\lambda-\rho}
}
\]

and for \(\lambda=\rho\),

\[
H_n
=
n\lambda^{n-1}.
\]

Thus downstream phase can retain a conditional association with pre-entry
physiology even after entry phase \(e_0\) is included.

## 4. Pure serial handoff is a special case

If

\[
\beta=0,
\]

then

\[
e_n=\lambda^n e_0.
\]

Likewise, if there is no physiological state that persists after entry, the
model reduces to the earlier pure handoff.

Therefore the persistent-state model nests, rather than replaces, the serial
two-clock model.

## 5. Biological interpretations of s

The state \(s\) need not be a clock oscillator.

It may represent:
- energy reserves;
- endocrine state;
- developmental condition;
- accumulated nutritional condition;
- another persistent consequence of pre-entry physiology.

This distinction matters for mule deer. March IFBFat is a nutritional state,
not evidence of one molecular seasonal oscillator.

## 6. Entry timing and persistent carry-over can coexist

A single physiological state can affect both:

1. **when entry occurs**;
2. **downstream timing after entry**.

This does not collapse the two clocks.

The decision controller still acts on signed ecological phase; the persistent
state adds a separate forcing term.

Conceptually:

\[
\text{physiological state}
\rightarrow
\begin{cases}
\text{entry timing}\\
\text{persistent carry-over}
\end{cases}
\]

while

\[
\text{phase information}
\rightarrow
\text{signed corrective decisions}.
\]

## 7. Identifiability boundary

With one downstream endpoint, the coefficient on \(s_0\) identifies only

\[
B_n
=
\beta H_n(\lambda,\rho).
\]

It does not separately identify \(\beta\) and \(\rho\).

Repeated physiological measurements or multiple downstream checkpoints are
needed to estimate a persistence rate.

Likewise, an observational conditional IFBFat coefficient does not establish
that IFBFat itself is causal. Unmeasured annual or route conditions can create
the same pattern.

## 8. Pairwise mismatch gains a third exact component

For actor \(i\),

\[
e_{i,n}
=
\lambda_i^n e_{i,0}
+
\beta_i s_{i,0}H_n(\lambda_i,\rho_i).
\]

Write the initial pair state as

\[
e_{1,0}
=
m_0+\frac{\Delta_0}{2},
\qquad
e_{2,0}
=
m_0-\frac{\Delta_0}{2}.
\]

Then

\[
\boxed{
\Delta_n
=
(\lambda_1^n-\lambda_2^n)m_0
+
\frac{\lambda_1^n+\lambda_2^n}{2}\Delta_0
+
\beta_1s_{1,0}H_{1,n}
-
\beta_2s_{2,0}H_{2,n}.
}
\]

The three terms are:

1. **controller-generated mismatch** — different downstream phase retention;
2. **entry-clock mismatch** — different phase at entry;
3. **persistent-state mismatch** — physiological carry-over after entry.

Thus even perfectly synchronized entry and identical controllers can later
diverge if persistent physiological states differ.

Conversely, when

\[
\beta_1=\beta_2=0,
\]

the result collapses exactly to the earlier serial two-clock theorem.

This decomposition is especially useful conceptually because it prevents a
conditional downstream effect of physiology from being mislabeled as a
decision-feedback gain.

## 9. Falsifiable predictions

A genuine persistent-state mechanism predicts that:

1. repeated measures of the physiological state decline or change with a
   measurable persistence structure;
2. its downstream timing coefficient decays with checkpoint distance according
   to the same persistence scale;
3. after accounting for physiological carry-over, signed phase error still
   predicts direction-specific behavior if a separate decision controller is
   present.

A pure handoff predicts no such residual physiological association after entry
phase is measured without error.

## 10. Relation to the H2 null

The negative IFBFat × DFP moderation result is compatible with this extension.

Persistent physiology enters **additively** through \(\beta s_k\), whereas H2
would require physiology to multiply the phase-to-action gain.

Thus:

- no H2 moderation;
- residual downstream physiological association;

can coexist naturally.

This is a sharper distinction than treating every state effect as a feedback
gate.

## 11. Relation to clock portfolios

The clock-portfolio theorem allocates precision between entry timing and
post-entry feedback.

Persistent state adds a third pathway:

\[
\text{entry precision}
+
\text{persistent physiological carry-over}
+
\text{feedback correction}.
\]

It can therefore create covariance between entry-clock investment and
downstream timing even when feedback gain itself is unchanged.

## 12. Claim boundary

Because this model was formulated after the mule-deer handoff result was known,
those data cannot confirm the persistent-state extension.

The mule-deer result may only be described as **motivating** a model in which
pre-entry physiology can persist downstream.

A direct test requires new or previously unopened repeated physiological
measurements across checkpoints.

## 13. Ecological statement

The most general serial-clock principle is therefore not:

> one clock stops when the next clock starts.

It is:

> **different timing mechanisms can hand off control while physiological state
> persists across the boundary between them.**

This keeps the developmental and decision clocks mechanistically distinct
without assuming their effects are temporally isolated.
