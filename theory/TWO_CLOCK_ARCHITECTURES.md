# PAYOFF-B prospective two-clock architecture

Date: **2026-10-03**  
Status: **post-freeze conceptual/mechanistic extension; frozen GEB V2 unchanged**

## 1. Why "the clock" must be split

Seasonal timing can be generated by at least two mechanistically different
architectures.

### Clock A — developmental / physiological timer

An internal physiological state progresses toward a threshold.  Environmental
conditions can change the rate of progression, but the organism need not
repeatedly estimate signed mismatch and choose a corrective action.

Examples include diapause termination, emergence, flowering readiness,
reproductive maturation and circannual migratory readiness.

This layer is called a **developmental/physiological timer** rather than a
"molecular clock" because molecular clock genes, endocrine regulation,
photoperiodism, thermal accumulation and other mechanisms can all contribute,
and their relative importance differs among systems.

### Clock B — inferential / decision controller

The organism repeatedly observes cues, estimates its current phase relative to
a moving ecological target, and chooses among still-available actions.

Examples include migration speed, stopover duration, route choice and local
departure decisions.

This is not a molecular clock.  It is a state-dependent policy / feedback
controller.

The informal "Mikawa-Anjo clock" should refer to Clock B: a checkpoint at which
the organism functionally assesses whether it is early or late and adjusts its
trajectory.

## 2. Minimal developmental-timer model

Let \(z_t\) be internal developmental/physiological state and \(\Theta\) the
threshold for a seasonal event.

In continuous time,

\[
\dot z(t)=v(E_t,z_t),
\]

where \(E_t\) includes temperature, photoperiod, energetic condition or other
proximate inputs.

The event occurs at

\[
\boxed{
\tau
=
\inf\{t:z(t)\ge\Theta\}.
}
\]

For a constant rate \(v>0\),

\[
\tau
=
\frac{\Theta-z_0}{v}.
\]

This is a **rate-to-threshold** mechanism.

The key property is that the timing response can emerge without an explicit
comparison between "my phase" and "the resource phase."

Once a one-way developmental transition such as emergence is completed,
recourse can be small even if later environmental information becomes perfect.

## 3. Minimal decision-controller model

The route-wise PAYOFF-B controller instead uses a phase estimate

\[
\hat e_t
=
E[e_t\mid I_t]
\]

and chooses a signed action

\[
u_t
=
\pi_t(\hat e_t,A_t),
\]

where \(A_t\) is the currently feasible action set.

Phase then evolves as

\[
e_{t+1}
=
\phi_t(e_t-u_t)+w_t.
\]

This is an **estimate-to-action** mechanism.

The same individual can act repeatedly:

\[
\text{observe}
\rightarrow
\text{estimate}
\rightarrow
\text{correct}
\rightarrow
\text{observe again}.
\]

## 4. Hybrid architecture

Most organisms should not be forced into a pure binary classification.

Let the developmental timer generate a readiness gate

\[
G_t
=
\mathbf 1[z_t\ge\Theta].
\]

The feasible decision set can then depend on that gate:

\[
A_t=A(z_t,G_t,\text{state}_t).
\]

The decision controller selects

\[
u_t
=
\pi_t(\hat e_t,A_t).
\]

The full architecture is therefore

\[
\boxed{
\text{physiological state}
\rightarrow
G_t\;(\text{ready})
\rightarrow
O_t\;(\text{opportunity remains})
\rightarrow
\text{information-dependent decision}
\rightarrow
\text{phase correction}.
}
\]

This is the most appropriate representation for migratory birds: endogenous
circannual and photoperiodic programmes can establish migratory disposition or
a broad departure window, while local weather, fuel state, stopover information
and route conditions affect repeated decisions within the migration.

## 5. Mapping to existing PAYOFF-B coordinates

The two clocks map onto different model objects.

| biological component | PAYOFF-B role |
|---|---|
| developmental state \(z_t\) | latent physiological readiness |
| threshold \(\Theta\) | event / commitment gate |
| timer rate \(v\) | plasticity of developmental schedule |
| readiness gate \(G_t\) | whether a class of actions is available |
| information weight \(K_t\) | quality/use of current phase information |
| control gain \(g_t\) | strength of state-dependent correction |
| feasible action set \(A_t\) | mechanistic basis of actionability \(r_t\) |
| phase retention \(\lambda_t\) | realized carry-over of timing error |

Thus \(r_t\) is not itself a molecular/developmental clock. It summarizes how
the physiological and ecological state constrains the actions that remain.

If actuator \(a\) has a readiness/availability gate \(G_{a,t}\in[0,1]\), then
the feasible action set is generated mechanistically by those gates,

\[
A_t=\{a:G_{a,t}>0\}.
\]

A simple reduced-form actionability coordinate can be written, when the
actuators have declared weights \(\omega_a\), as

\[
r_t
=
\frac{\sum_a \omega_a G_{a,t}}
{\sum_a\omega_a}.
\]

This weighted average is only one possible reduction, not a universal
definition of actionability. Its purpose is to show how developmental/
physiological clocks can generate the shrinking action space represented by
\(r_t\).

Similarly, \(K_t\) and \(g_t\) belong to the decision-controller layer, not to
the developmental timer.

## 6. Why the distinction matters for mismatch

Two species can show the same observed phenological shift but have different
clock architectures.

### Developmental-clock mismatch

A cue changes \(v\) or the threshold-crossing time \(\tau\).  Once the event
occurs, later correction can be limited.

Expected signature:
- strong dependence of event timing on accumulated or entraining cues;
- little signed post-event correction;
- actionability collapses near/after threshold crossing.

### Decision-clock mismatch

The event trajectory is repeatedly adjusted according to \(\hat e_t\).

Expected signature:
- incoming signed phase predicts action direction;
- early and late errors trigger opposite corrections;
- repeated checkpoints can produce a phase-variance funnel;
- correction strength depends on cue information and remaining actuator
  capacity.

### Hybrid mismatch

The physiological timer determines when the organism becomes ready to act;
the decision controller then determines how remaining error is corrected.

A climate anomaly can therefore alter:
- readiness timing;
- information quality;
- available recourse;
- feedback gain;

independently.

## 7. Bee-versus-migrant contrast

### Bee emergence / developmental events

The useful abstraction is usually a developmental/physiological timer:

\[
z(t)\rightarrow\Theta\rightarrow\text{emergence}.
\]

Temperature, photoperiod, diapause physiology and molecular clock pathways can
change \(z(t)\) or the threshold process.  The key PAYOFF-B feature is
**thresholded readiness with relatively low post-emergence timing recourse**,
not the assumption that every bee uses one molecular oscillator.

### Migratory bird

A migrant can have both layers.

An endogenous/photoperiodic programme contributes to readiness to migrate, but
once migration begins the bird repeatedly chooses when to depart a stopover,
how long to remain, how quickly to travel and sometimes which route to take.

The route therefore contains repeated decision clocks:

\[
\text{readiness}
\rightarrow
\text{depart}
\rightarrow
\text{stopover decision}
\rightarrow
\text{next stopover decision}
\rightarrow
\text{arrival / breeding decision}.
\]

The "Mikawa-Anjo clock" is specifically one of these **decision checkpoints**,
not the endogenous annual programme.

## 8. New comparative prediction

Species should not be classified only by "phenological sensitivity."

They should be classified along at least two axes:

\[
\boxed{
\text{timer plasticity}
\times
\text{feedback recourse}.
}
\]

This yields four qualitative architectures:

1. rigid timer + weak feedback — high vulnerability;
2. plastic timer + weak feedback — good initial tracking but little rescue;
3. rigid timer + strong feedback — poor initial tracking but strong downstream
   compensation;
4. plastic timer + strong feedback — both anticipatory and corrective
   capacity.

The third class is particularly important: apparently poor departure tracking
can coexist with accurate final timing because feedback corrects a rigid or
remote-cue initial schedule.

## 9. Pairwise mismatch prediction

For interacting species, clock architecture differences can generate different
effective retentions

\[
\lambda_i
=
\phi_i(1-G_i g_iK_i),
\]

where \(G_i\) is the readiness gate generated by the physiological timer.

Developmental-timer differences primarily alter \(G_i\), event timing and the
feasible action set. Decision-controller differences primarily alter
\(K_i\) and \(g_i\).

The controller-asymmetry theorem then converts those differences into
interaction mismatch:

\[
\Delta_{t+1}
=
(\lambda_1-\lambda_2)m_t
\]

for an initially synchronized pair under common environmental innovation.

Thus the two clocks are not competing explanations. They enter different
factors of the same effective retention coefficient.

## 10. Empirical discrimination

A direct study should ask separately:

### Timer layer
- What internal/developmental state predicts readiness?
- Which environmental variables change timer rate or threshold crossing?
- Is the transition reversible?
- How much timing variance is fixed before the focal action?

### Decision layer
- Does signed incoming phase predict the next action?
- Do early and late errors trigger opposite actions?
- Does checkpoint information improve downstream prediction?
- Does removing an actuator increase phase retention?

The two layers should not be inferred from the same response variable without
an identification design.

## 11. Novelty boundary

Developmental timing, diapause physiology, circadian/circannual clocks,
state-dependent migration decisions and feedback control all have extensive
prior literatures.

PAYOFF-B should claim only the synthesis:

> **Seasonal timing can be generated by a physiological readiness clock and
> corrected by a separate information-dependent decision controller; climate
> mismatch depends on how these two layers are combined within each interacting
> species.**

The "Mikawa-Anjo clock" is a communication label for the second layer only.


## 12. Literature anchors

The two-clock distinction is a synthesis across established literatures rather
than a claim that either mechanism is new.

### Developmental / physiological timing

Saunders (2020), *Annual Review of Entomology* 65:373–389,
DOI 10.1146/annurev-ento-011019-025116, reviews insect diapause,
photoperiodic time measurement and molecular studies of circadian clock genes.
The review explicitly shows that clock-gene involvement does not imply one
universal oscillator: both oscillator-like and hourglass-like responses occur,
and multiple peripheral oscillators can contribute.

This supports the manuscript boundary:

> insect emergence/diapause can involve molecular/circadian clock pathways, but
> "molecular clock" should not be used as a universal label for bee emergence.

### Migration readiness plus flexible decisions

Gwinner (1996), *Journal of Experimental Biology* 199:39–48,
DOI 10.1242/jeb.199.1.39, reviews circadian and circannual programmes in avian
migration and documents an endogenous annual timing basis for migration onset.

Åkesson & Helm (2020), *Frontiers in Ecology and Evolution* 8:78,
DOI 10.3389/fevo.2020.00078, explicitly frame migration as an endogenous
programme that also permits flexible responses to environmental information at
different stages; experienced migrants can use information acquired on
wintering grounds, breeding grounds and en route.

The departure-decision literature further supports the distinction between an
underlying endogenous schedule and realized decisions modified by intrinsic
state and external conditions.

These sources support the hybrid architecture:

\[
\text{endogenous readiness}
+
\text{environmentally informed decisions}.
\]

They do not imply that physiological readiness \(G\), information weight \(K\)
or decision gain \(g\) have already been separately estimated in the natural
systems used by PAYOFF-B.
