# Data and code access for initial review

The analyses use two previously published public source datasets:

1. Amaral et al. (2025), *Diversity and Distributions* 31:e70033,
   doi:10.1111/ddi.70033. The bird analyses use the public source dataset fixed
   to source-project commit
   62c58d77c2028bd863dfe3697b0d9cf29ceaeab0.

2. Ortega et al. (2023), *Nature Communications* 14:2008,
   doi:10.1038/s41467-023-37750-z. The mule-deer analyses use the public Source
   Data workbook accompanying that article.

For double-anonymous review, the manuscript-specific analysis code, analysis
contracts, frozen figure data, selected tests, and an explanatory README are
provided in the anonymous reproducibility archive generated by:

`scripts/build_payoff_b_v45_reproducibility_bundle.py`

The review archive is screened to exclude submitter-identifying names and
repository account identifiers.

At publication, the final code/archive should be deposited in a permanent
curated repository with a DOI, and the final Data and Code Accessibility
Statement should cite that archive.
