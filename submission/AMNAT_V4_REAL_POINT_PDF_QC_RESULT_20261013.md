## Scientific and submission boundary

The originally registered broad degradation of external source–target
green-up correlations was NOT SUPPORTED. Sampled correlations instead
strengthened (mean delta rho +0.3690; 95% pair CI +0.2984 to +0.4365).
The preregistered negative transfer to better bird timing was also NOT
SUPPORTED (+0.06244; CI -0.01411 to +0.13635). A fixed-arrival null
reproduced an apparently positive slope, so no bird-specific increment
was detected.

These results do not establish that birds perceived improved information,
that their actions were constrained, that a causal adaptive response
failed, or that survival/reproductive fitness changed.

The current PDF is a genuine anonymous *editorial preview*, not a
journal-upload-approved manuscript. Machine extraction and selected
page rasterization are not complete human visual inspection. The full
anonymized reviewer-accessible source/processed-data and code archive,
source reuse permissions, journal-style citation verification, author
contribution/funding/COI/AI disclosures and final author approval
remain open. Do not call the current GitHub Actions artifact a full
anonymous reviewer-data repository or completed journal submission.
