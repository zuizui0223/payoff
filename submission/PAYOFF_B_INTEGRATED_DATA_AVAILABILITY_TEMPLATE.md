# Integrated tracking ecology — Data and Code Availability template

The analyses use previously published public datasets or archived source data.
Reproducible analysis code, registered claim boundaries, machine-readable
result receipts, and derived non-sensitive outputs will be provided through an
anonymous reviewer-access repository during peer review and a persistent public
archive after acceptance or publication, subject to the source-data licenses.

Original datasets remain available from their cited source repositories and
DOIs. The manuscript does not redistribute source datasets whose licenses or
archive terms require users to obtain them from the original provider.

Before submission, replace this template with the verified anonymous reviewer
URL and confirm logged-out access without exposing repository ownership.
